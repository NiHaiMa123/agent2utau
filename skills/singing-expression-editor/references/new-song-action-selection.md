# 新条件的动作选择与阶段判断

先读[条件到函数](source-condition-to-function.md)。本页用于审查决定是否真的由当前源观察产生，特别是生成仍像平台、换参数却同形或作者路线借用被称为设计时。

逐句确认主音、到达、声母／元音、实际可用主体、音乐焦点和后字关系。把起头、稳定主体、周期及准备分开；长字再根据音乐过程决定维持、展开、回收、暂停与再进入，不固定阶段比例。源周期失败保留unknown，既不自动无周期也不自动补周期。

每个决定说明当前的可观察条件、动作目的、函数及实际参数、一个被拒绝的合理备选、局部预期与不确定性。把条件改变时应改哪项说明清楚，例如：落拍必须清晰会改变到达时间与台阶选择；下一换音更近会缩短展开或提前收幅；同元音延续会保留相位，而换字可能选择局部发音动作。不能只写“推进所以用某profile”或按时长挑一条最接近的作者线。

检查以下替代性解释：

| 现象 | 先排查 | 设计修订 |
| --- | --- | --- |
| 大滑音后中段仍平 | 总音域是否来自到达／尾部准备 | 重新决定主体有限运动或周期支撑，单独检查主体局部 |
| 长字一直同样摆 | 是否只有恒速正弦与线性深度 | 按当前维持／回收／展开分别重设计存在区与中心，允许停止 |
| 短字无动作 | 是否以时长／源周期门槛自动给平台 | 判断能否用一次有限弯折、直接到达或明确保持 |
| 换音成尖峰 | 是否以巨大PITD抵消硬基底 | 检查全部唱音与AP/SP边界及点间／网格相位，不只平滑函数 |
| 音高有波仍僵 | 是否发声／音量未规划或实际未执行 | 独立选择非pitch有限控制，并核对真实输入；不随手多加波 |
| 条件说明不同但结果相同 | 是否标签未被执行器消费或固定模板分发 | 检查实际参数和输入依赖，补接口，不能仅扩写理由 |

函数和实际生效的参数变化要能支持所述改变。选择质量审阅独立于覆盖、C1、局部范围检查与F0跟随。相似条件的作者反例用于修正规则，不能再次改为按作者ID派发。已经揭示参考的歌曲作为开发资料；前向设计和新音频听感仍需独立验证。
