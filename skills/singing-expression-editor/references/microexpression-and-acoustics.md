# 细部画线与声学解释

适用：主旋律大致正确、执行检查通过，仍有机械感，或需要从参考归纳细部技巧。读图须兼顾完整乐句与局部放大。以下是条件下的候选处理及可检验解释，不是作者意图记录，也不是任何歌曲的默认参数。

## 声学依据与推测边界

声乐合成研究将换音过冲、换音前准备、周期波动及细小变化分开处理，实验表明它们均可影响歌唱感知；这支持除主音与颤音外还要审阅细部，不能推出每个字都必须具备全部动作，也不能把论文中的固定模型系数移植到当前声库。[Saitou等，歌唱声学特征研究](https://www.isca-archive.org/interspeech_2004/saitou04_interspeech.pdf)

汉语演唱研究区分声母、元音的起头／持续／释放与鼻尾；音符起拍和发音起点并非同一边界，邻音也可影响单音符字的曲线。这为按实际音素阶段安排动作提供依据。该研究的特定合成器和手工分段不是当前模型已验证的行为。[Wang等，汉语演唱表达分析](https://arxiv.org/pdf/1502.04300)

颤音的速度与幅度共同影响是否被听成颤音；看起来近乎稳定的线，也可能有浅小运动。可见小波不能自动等同于可听自然度，一两音分的量化折点更不能一律解释为作者刻意设计或真人生理颤动。[Non-Vibrato感知实验](https://www.sciencedirect.com/science/article/abs/pii/S0892199715002234)

发声源经过声道滤波后，音高波动和输出强度波动可以呈现不同关系，并受元音影响；不应把音高峰直接当响度峰或按同相正弦追加DYN。[声源—滤波器与颤音的实验](https://www.sciencedirect.com/science/article/pii/S0892199721002812)

据这些机制推测参考的音乐目的时，用“可能为了……”并给反例与验证办法。自然歌声的发声机制不能直接映射为TENC／VOIC数值。不同元音、音区、声线及上下文的响应要在当前模型上确认；响度与频谱共同变化也不能归结为某一条音高线。[声源随力度变化的研究](https://www.isca-archive.org/maveba_2005/sundberg05_maveba.html)

## 字头与换字：先分清听得见的支撑

| 条件 | 候选处理 | 为什么可能这样画／如何核查 |
| --- | --- | --- |
| 前字连向新字，声母早于元音开始 | 把前字保持、离开、声母内准备、元音到达分别锚定；不要围绕音符边界对称分配滑音 | 可能为保住前字主体并让新字清楚进入；核查下探是否侵占前字韵腹、主音是否及时到达 |
| 新字与前字同记谱音高 | 审阅重新咬字，可选短回收／准备或直接连接；新字主体仍保有清楚落点 | 相同主音不意味着相同发音事件；短暂偏离可能塑造换字，不能全程保持旧字周期而吞字，也不能每字都加深谷 |
| 入口含局部谷、随后恢复到主音 | 声明离开—谷—恢复—到达；如需小过冲，另定回收，不把整个过程变成一次单调滑入 | 可能塑造有起落的起声与到达；检查最终线是否真的先降后升，以及是否误唱了经过低音 |
| 入口到主音较晚，但元音有足够支撑 | 可选延迟到达，先给入口作用，再给稳定主体；与直接到达作比较 | 可能形成拖入或较柔的入口；延迟并非普遍人味技巧，过晚会显得跑调／迟疑，短字尤其需谨慎 |
| 很短的字不容持续周期 | 可用一个有限局部回收、轻抬／落或无额外动作；避开重复起伏 | 保留发音和方向比塞入规则颤音更合适；检查实际韵腹仍有可辨主体，而非把全部时长花在转音 |

清辅音、AP/SP等区间没有可靠有声F0时，工程的有限载频只服务模型接口。较大的谷若位于这类区域，不能用其数值声称元音必须下探这么深。先看原生归属，再看渲染波形的有声／未知区；鼻音、滑音等可能有声，不能把所有辅音当静音掩盖错音。具体音素类别与实际声学有声支撑也要区分。

## 主体：近乎平稳与完全抹平不同

先按[整句尺度与字腹运动](phrase-scale-contour-study.md)确定运动落点、阶段和反例，再放大细节。源线整体平滑再缩幅不是字腹设计；滤波可能按速率不同程度衰减，删掉局部折返。核查非零变化不能接受这种失真，也不因此要求所有字在普通视窗显出大波。

**稳定主音、轻语气或承接字**：允许近乎平稳，但审阅到达后的轻抬／落、一次浅回收、短保持和下一字准备。可能在保住旋律的同时留发音姿态。需要运动时用有限稀疏节点，给方向、位置与恢复；不随机加抖动，也不把全部量化折点当生成动作。

**平稳后需要展开**：先独立规划稳定段、浅变化段、连续周期段；位置依乐句作用与实际韵腹选择，不按固定音长比例或最低检测时长触发。可能使持续音从陈述走向展开，但主歌克制不能使所有持续字无起伏。

**中心缓移、局部波动同时存在**：分别安排主旋律、慢中心走势和快起伏。比较峰谷时按当前音乐阶段的中心，而非整个字的首音或去重音列表；慢漂移不能误计成周期深度。保持允许的中心偏移与主音落点，不能靠装饰掩盖主体跑调。

**近邻阶段有不同小动作**：保留有作用的方向反转与短保持，不把全字压成少数平均值再套单一弧线。压平可能丢失起头回收、主体轻推或尾部准备；反过来，重复段出现同形原例也不证明必须随机改写。细节取舍依据当前上下文和试听，而非每字必须不同。

## 周期：逐周期形态与存在区域一起选择

| 条件 | 候选处理 | 细部核查 |
| --- | --- | --- |
| 持续音由浅逐步展开 | 允许分阶段、非线性的深度变化，同时独立选择速度 | 首几波是否真的浅、展开位置是否合适；不以一条线性增深包络覆盖全部长字 |
| 中段展开、后段回收 | 保留深→浅、停止或转慢释放的选择 | 后段是否继续重复深波；参考序列结束后必须重新选择剩余支撑 |
| 同样平均速度但波形仍机械 | 核查每周期峰间时距、峰谷位置、正负偏差及中心走势；有依据时允许不对称 | 峰→谷与谷→峰不必严格等时，也不必每峰每谷等幅；不强制随机化、锯齿化或提高频率 |
| 周期近似存在但极浅／零散 | 作为浅小运动或局部动作审阅，不强行标为持续规则颤音 | 检测prominence和采样量化影响必须留账；零散微峰不自动计成完整周期 |
| 音高在持续元音内换到下一音乐目标 | 主旋律转向单独安排，周期按实际持续关系连接或调整 | 不把换音跨度当颤音幅度，同音延续不按音符重起相位 |

各峰、谷、相邻峰不等高时，半幅不能直接充作峰值，也不能补一个对称负谷。按实际秒数定义局部频率，周期数量由可用支撑与速度产生。自然演唱不是随机曲线；不对称和速度变化只是可以选择的维度，不是故意不规则就更像人的保证。

连续周期的深度与TENC可以朝不同方向变化。可能同时表达音高展开和发声释放；这不允许强制越深越紧、越深越响或宣称下降张力一定更自然。实际虚实变化需按[声线与稳定性](voice-baseline-and-stability.md)分层试验。

## 收尾：不要遗漏最后半波和韵尾

句尾停顿、连向下一字、持续元音内部转音分别决定。给韵腹最后可用段、韵尾、周期退出、下一声母和AP/SP明确相对关系。可能的目的包括保留尾字、给后字准备或结束发声，不能从图上独立确认是哪一种。

周期停止时核对第一和最后部分波，不能只数完整周期；可以继续物理相位配独立渐隐，或明确转入另一释放动作。若要尾部下行，不把最后一个谷随剩余时间拖成长低音。周期退去后仍需安排中心与声学释放，不能认为偏差回零就自动唱出了自然尾音。

保留尾部可懂度和已选主音，检查尾声母／鼻尾、后字进入以及模型实际有声支撑。需要柔和结束时，可独立提出发声或包络候选；避免在元音仍承担主旋律时提前消掉支撑。单纯恒定增益不会重建发声方式，逐字拉平也可能抹掉已有句内层次。

## 落实细节的核查方法

同时查看整句、完整字和局部放大，标出实际音素、主音阶段、峰谷和速度。局部审阅记录入口次序、浅／深段位置、中心方向、逐周期不对称、起尾部分波及邻字关系；这些是计划内容，不保证现有CLI已实现。

将选中细节映射为`melody_nodes`、`local_gesture`、`body_landmarks`及已有周期接口；函数仅执行，需核对支撑、端点、斜率与堆叠预算。采样／整数编码可能抹掉极浅动作，曲线叠加也可能抵消极值；比较最终原生线的有序节点与局部幅度，而非只查组件参数。接口无法表达时先补接口或标unsupported，不偷换成平台。

提出声学解释后，验证应对应解释：只改入口则检查到达与咬字；只改浅运动则检查主体；只改周期退出则检查末波及尾音；只改发声则检查实际条件和输出。固定其它条件与上下文，重新计算变化所依赖的状态。独立对照一次只支持相应局部假设，不能证明作者动机或所有AI感的原因。

声音偏好还依赖听者与音乐语境；统计指标不能代替真实听感。[歌声偏好实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC11026466/)。因此仅由文档、图或原生执行通过不能宣称学会人味。具体歌曲证据、参数和反馈留在项目研究记录；Skill只保留以上条件、候选处理与核查方法。
