# 多通道发声与长音阶段

用户指出只有 pitch、有长音却像一串相似波浪、波形显得没有发展，或要求学习非 pitch 曲线时使用。先分别识别最终音高线、编辑器的控制曲线与音频振幅包络；它们不是同一个量。没有 DYN 不表示声音无强弱，写了 TENC 也不保证音量或自然度改善。

## 先决定改变什么

把每个实际元音及同元音延续放回整句：到达后是在陈述、维持、继续推进、再强调还是结束？依据语义、前后旋律、实际时值和声库响应决定，不用角色标签或“长于某秒”直接分派固定函数。检查相同音区／近似时值的克制反例，以及同一表达在不同段落是否真的需要同样展开。

每个字分别记录以下决定，允许某通道明确保持：

| 层 | 要回答的问题 | 可执行的动作 |
|---|---|---|
| 音高中心与换音 | 主音到达后是否继续抬、回落或换音？ | 具名旋律节点、有限主体弯曲；多音字分音乐阶段 |
| 局部波动 | 何时浅、何时展开、是否暂停后重启？ | 分段峰谷／深度／速率／中心／非对称；保持相位衔接 |
| TENC | 当前阶段是支撑、放松、重新支撑还是保持？ | 建立—保持—回落，或恢复后再展开的慢包络 |
| BREC／VOIC | 是否有证据需要更气、收实、减弱发声成分？ | 单独安排元音内的有限变化；不自动绑定音高周期 |
| DYN | 最终音频的强弱是否偏离本次选择的力度走向？ | 有目的的输出包络；不把所有字拉成同样响 |
| 声线／SHFC | 是表达包络问题还是声线与模型条件问题？ | 单独校准完整依赖，不能作为填满空白曲线的装饰 |

“保持”应注明当前基底和理由。不能让工具缺乏通道支持偷偷变成保持；也不能为了让编辑器每栏都有线而全字加控制。

## 长音不要只拥有一个包络

先安排有音乐作用的阶段，再给各阶段秒数和节点。以下是候选顺序，不是每个长音必须套用的模板：

- 到达有局部回收，主体保持浅运动，末段才展开。适合主音已经明确、后段承载余韵的延音；需要持续推进的主体不宜长时间停留。
- 一组明确起伏后收浅或暂歇，语义或旋律需要时再开启下一组。中间不是把末周期无限循环，也不必重新下探或重发音。
- 主体已有展开，后段波动缩小、中心缓落，发声逐渐松开。接着强拍进入的连唱不必彻底泄掉支撑。
- 保持浅、不形成稳定周期，但在进入、维持和退出的斜率、中心、发声状态上有选择。长时值本身不要求深颤音。
- 同元音转音：先完成主旋律换音与到达，再重选该阶段的波动。不得把跨主音峰谷统计成一个巨大颤音。

阶段边界来自主音稳定、音乐重心、局部回收、下个音／字准备及真实尾音，不把全字等分，也不统一放在固定百分比。较长主体若一直沿同一速率／对称性／深度公式走，重新检查是否漏掉“收浅／维持／再展开”的判断；不是强制增加一个波。

每段周期独立给出存在与否、支撑区间、有序峰谷、中心移动、速度演变和最后部分波。新段可延续相位，也可先衰减到浅运动再进入；禁止突然切相位。有限主体弯曲和周期深度是不同层，不能靠放大整条源残差同时替代。

## 发声包络和 pitch 可以不同步

相邻字句虚实不连贯时，按[虚实连续性](phonation-continuity.md)先定义整句走向与继承关系。相对平台和针对预测偏差的有限补偿是不同的执行模式；不要把逐字补丁或BREC默认值冒称稳定发声基底。

用户反馈有气无力时先按[转音与支撑推断](expressive-turn-and-support.md)检查实际预测基底、动作和音素。长支撑尚未结束，不能仅凭尾字身份把减TENC、增BREC、减VOIC联动；局部存储TENC为正不证明最终张力充足。音高与发声候选分别对照，再判断是否组合。

| 条件与目的假设 | 首轮处理 | 反例与检查 |
|---|---|---|
| 主体支撑已经充分，尾部需要松开，但仍保留音高余韵 | TENC 先保持、再下降；pitch 周期可以后展开或继续 | 颤音变深不自动要求张力升高；检查尾音仍可辨、后字未被拖弱 |
| 字头／换音后需要由松到实，之后稳定 | 元音建立后有限抬升 TENC，达到局部平台；BREC 可保持 | 短辅音不能被包络提前覆盖；高音、长音本身不要求加张力 |
| 声音偏虚且目标是收实 | 单独提出降低 BREC 的候选，与只改 TENC 比较 | BREC 与 VOIC 不互为正负旋钮；特征变化不等于输出 dB |
| 句尾需要气化退出且当前响应支持 | 较晚改变 BREC；必要时再另试有限降低 VOIC | 不把每个尾音变气，也不在早期丢掉元音；VOIC 已达上限不能继续加 |
| 长音需要再次推进 | 先有保持／回收，再独立恢复 TENC；pitch 是否同步由音乐作用决定 | 不强制所有通道同时达到峰值；保持邻接基底连续 |
| 只是最终力度不够或局部包络塌陷 | 在最终声学条件下单独试 DYN | 张力不是音量修复器；不复用旧声线／旧pitch的逐字增益 |

以上是从可见控制归纳的工作解释，不是已知作者心理或已证实的生理因果。稀疏控制里的长平台也是明确选择；量化折点无需逐点复制为“人味”。

## 主动给首轮数值，但不当通用常数

先读取当前工程及原生的上下限、默认值、单位和实际响应。下面是当前已校准声库上可用于**单因素首轮试验**的设计候选，不是参考曲的分位数，也不是听感验收门槛；换库须重新校准。相对已选基底计算，越界时重新设计，不裁剪后声称执行成功。

- 温和支撑：先试 TENC 相对基底 +10～25；松开先试 −15～40。只选一个明确候选，不扫参数挑有利结果。当前原生 TENC 每 20 单位对应张力输入 +1，最终仍受特征范围裁剪。
- 气声变化：先试 BREC 相对基底 ±10～25，符号依目的选择；当前每 10 单位对应气声输入 1.2。收实和气化分别验证，不假定负气声自动等于更响。
- 有目的地减弱发声成分：VOIC 先试相对基底 −5～12；当前每下降 10 单位对应发声输入 −1.2。默认／上限是 100，禁止以旧工程超过 100 的写入值证明当前可继续增强。
- 元音内建立可先试 80～180 ms，松开可先试 180～450 ms；需要更长渐变时依据实际主体安排约 0.4～1 s 的推进／回落。这些是工程起步值，不能覆盖辅音、塞进太短元音或把每个长字按比例拉伸。
- 若已明确选择力度包络，可先试约 1～2 dB 的单独候选（DYN 10～20 单位），并保持整曲公共增益。没有输出力度问题不自动添加。

一次先比较选定通道，再决定是否需要组合；不要拿组合有效来证明每条控制都必要。原生数组证实数值进入模型，与实际声音更自然是两个结论。

## 可执行计划与接口

完整计划每个阶段写明：触发条件、目的假设、反例、实际元音／乐句锚点、pitch动作、各控制通道的基底／节点／保持理由、离开与恢复、需要重建的依赖。阶段允许跨同元音音符；不能跨新字自动沿用旧字的尾部状态。

附带 [compile_control_overlay.py](../scripts/compile_control_overlay.py) 的 `compile_overlay(curves, events, anchors_ms, ms_to_part_tick, descriptors)` 编译明确给定的 TENC／BREC／VOIC／DYN 叠加计划。它不选动作，不调用模型，也不自动写文件。调用约定：

1. `anchors_ms` 来自当前目标原生音素时钟；转换函数输出当前声部相对 tick，须考虑真实 TempoMap 和声部起点。
2. 每个事件有 `channel`、`purpose`、`allowed_ms` 与按时序排列的 `nodes`。节点包含 `anchor`、`offset_ms`、`delta`，使用当前通道存储单位；DYN 不是直接填 dB。
3. 首末 delta 为零，恢复的是原有基底，不是强制通道值归零。尾部仍需保留负张力时，应在允许的后续过渡支撑中安排恢复，或与下段共同规划，不能为满足工具而在元音尾端突然抬回。
4. 同通道重叠、时间乱序、tick 合并、越界、未知通道和无定义的非默认边缘延展均报错。原有曲线节点参与叠加，未选通道保留。调用方必须核查允许区间没有吞入不应改变的辅音／呼吸／邻字。
5. 参数范围由当前原生描述传入；SHFC／speaker 不走此接口。它们改变条件依赖，不能靠多加一个缩写假装得到支持。

当前 pitch 的 schema3 不自动消费这些控制事件。必须另行调用控制接口，将返回曲线写入候选 USTX，再原生读回。仅在 JSON 写 `phonation_choice` 或只生成 PITD 不算完成。

## 验证完整链

先看同一物理时间轴的最终 pitch、音符中心、TENC／BREC／VOIC／DYN 和当前实际声线。使用普通钢琴卷帘尺度审阅连续上下文，再放大浅变化；超出纵轴的转音另画完整范围，不能被裁掉后误判平稳。

原生读回要分四层：原文件写入值、当前加载后有效值、重采样后的特征增量、模型最终输入。旧声库／旧版本的越界值保留为历史证据；不要直接迁移。TENC／BREC／VOIC 单独变化时核对未选通道、pitch／phones／speaker及variance输入保持一致，按原生增量和合法范围形成新acoustic输入；pitch／speaker／SHFC等条件变化时重建variance，不复用旧状态。

SHFC不是PITD的同义词：当前接口把toneShift送入variance的pitch及特定声码器配置下acoustic的F0条件，而声码器F0另有路径。先查当前实现与实际输入，不直接把存储SHFC加到编辑器pitch后冒称最终发声音高，也不能当纯输出增益。

最后检查新音频的 F0、实际短窗振幅、边界、削波与组装。共同条件／随机输入和相同公共增益才能支持受控比较；更大的波形、更多曲线、周期计数都不能证明更自然。没有音频感知工具时明确标记未试听。接口合成试验成功只证明接口，不证明歌曲已重做或风格已掌握。
