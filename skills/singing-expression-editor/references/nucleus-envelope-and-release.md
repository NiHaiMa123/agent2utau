# 元音核的局部掉声与过早释放

## 先确定掉声发生在哪里

把反馈绑定到实际交付PCM与当前音素时钟，区分元音入口、主体、旋律换音、尾音、辅音及吸气。整字中位声能、连续控制值、F0跟随正常都不能排除字内短暂漏声。用真实秒尺度同时看原始合成声与最终输出；以约20–50ms窗、5–10ms步长起步，并用另一个窗长复核。窗内周期数太少时需要扩大；短字不得借用邻字或声母的能量当作自己的主体。

整曲每字登记早、中、晚段和持续局部低谷，同时登记左右连接与重复句。筛选的落差阈值只是审阅队列，不是“坏音”分类器或自动修复触发器。下行旋律、轻读、鼻尾、收束和真正休止提供反例；同一复合韵母内部可能已有滑音或鼻化，不能把整个单一音素都视为同质口腔元音。无法定位的阶段保留不确定性。

## 分开三种原因与处理

- **原始声正常、最终声掉落**：核对DYN单位、节点、原生取样与拼接。有限包络应经过词内连接，不按字界回零。修复原生路径，不另写一条与工程不同的音频增益。
- **原始声的核本来弱**：核对当前预测、最终发声输入及真实声学响应。发声参数是候选手段；隔离试验若未恢复主体，拒绝继续加张力或减气声。有限DYN可以改善可听能量，但不能声称它恢复了有声成分、正确元音或自然音色；已经释放成噪声的部分不能无限抬升。
- **腾气口后短字提前收尾**：比较旧／新实际元音时长、核内声能低谷、预测衰退与下一声母。模型的终止衰退可能占掉短字的主体。先提出恢复必要元音、重排附近准备或选择其它语义边界的方案，再用完整当前上下文的隔离对照验证。AP数量和连续唱段时长达标不能证明这个字仍完整；不能只因补气便认为所有截短都可接受。

不存在统一的最短元音或吸气时长。保留拍点和字序，明确艺术释放改动；不能偷偷移动原曲未知时钟，也不能把另一个工程的字长移植过来。新增或缩短气口的取舍仍需检查两侧声母、必要尾音和可理解的主体。

恢复或延长元音后，重新检查下一句准备函数的支撑起点及点间过渡。旧准备可能原本位于非唱区，如今却侵入延长后的字尾；必须按新边界重选支撑，不能只重算PITD而保留侵入。原生误差或相位误差小，只证明软件跟随了目标；目标本身的急降仍需在实际秒／半音尺度检查。

## 选择自己的有限函数

确认主体可承载后，Agent选择进入、承托、局部恢复和退出节点及幅度，不用逐帧声能反函数、逐字归一化或复制作者数组。入口弱可以早承托后退回；换音后弱可以在低音阶段有限恢复；正常收尾保留衰退。连续两字都弱时可用跨字支撑，避免给前字抬升后立刻回零又使后字失去存在感。审查旧补偿是否仍适合当前新预测；上下文改变后原来的增益也可能变成过补偿。

对未修改部分明确保留理由。审阅所有筛出的持续低谷和邻字落差，而不只审阅用户时码。全部字的记录应区分自然释放、弱读、补偿、几何重排和未确认；函数变化数或平均声能不能替代这些判断。

## 验证实际交付

发声或音素条件改变，重合成完整受影响上下文；只有后处理包络改变，才按依赖哈希复用既有波形。隔离基线必须重现交付时实际使用的预测和随机种子，不能把缓存预测冒充重新预测的数组。首先验证基线，再比较单因素和组合。

最终检查原生工程、实际ApplyDynamics与PCM，重新测所有元音、连接、AP/SP、尾辅音和峰值。对指定主体阶段记录改善及未达到之处，不能用整字中位数覆盖局部失败。保持相同伴奏和全曲增益截取对比，并把模型输入、声能代理、听觉认可分别报告。
