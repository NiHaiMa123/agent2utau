# 原曲与作者资源：研究处理，不生成路线库

本文件是研究入口，文件名保留供既有链接使用。默认生成方法见[条件到函数](source-condition-to-function.md)；旧的“提取参考路线再映射第一版”不再是此Skill的生成路径。用户以后明确要求逐点复刻时另行声明复刻任务及来源，不能借研究授权自动切换。

## 分开三种输入

| 输入 | 能观察什么 | 不能代替什么 |
| --- | --- | --- |
| 原曲GAME事件 | 候选音乐音高、起止、换音顺序 | 逐帧F0、元音时钟、字腹峰谷 |
| 原曲逐帧F0及可靠性 | 到达、持续波动、换音与释放的实测候选 | 自动风格目标、已确认的歌词字界 |
| 作者工程与当前原生读回 | 书面音符／表达、最终线与实际音素支撑 | 历史音频、作者动机或新曲应该采用的参数数组 |

先记录原文件／模型／分离器／版本与哈希、轨道／part范围、移调和两边时钟。全球偏移只用于粗窗口；逐字对应还要独立核查音乐与音素身份。未经核实的窗口明确为unknown或暂定，不能拿误配或八度错误推导作者改法。保留所有声部范围、未匹配延续与短字反例。

## 研究一次处理

先看整句再看元音各音乐阶段。区分原曲主旋律、起头装饰、同主音运动、下一音准备与非唱载频。保存物理秒、绝对cents与相对当前中心；原曲未知段断线，不能补成“原唱无变化”。音乐范围大不等于主体颤音深。

为一个可复核现象记录：原曲可观察条件；作者改变／保持的动作顺序与存在区域；可能目的；一个相似条件却处理不同的反例；什么额外条件能帮助选择；准备如何自行用函数实现。目的用假设语气；不能从作者线反推其未经记录的决策。

研究数值可描述条件下的到达耗时、有限弯折幅度、中心走势、峰间秒数、逐周期深度和控制变化。统计不直接组成生成字典。对整字和稳定主体分别测量，避免字头／尾部大跳掩盖平直主体。必要去噪单列前后差异，不把滤后线用于制作目标。

## 资源边界

原始曲线、样本、图册、歌词、时码、来源与失败案例放在项目研究资源索引；Skill中只写可用于新条件的处理及反例。生成器不能加载author样本／profile并裁剪、移调、重定时、稀疏拟合后称为Agent自行画线。程序只访问当前源观察和Agent明确选择的函数参数。

从资源研究得到候选规则后，用不带作者目标的输入做前向设计：选择函数、支撑和参数，算出曲线，再对照计划形态。揭示参考后的解释不算前向判断成绩；已见曲仍是开发资料，不能作未见曲考核。原生曲线可复现与试听接受另记，研究记录本身不提升训练资格。
