# 条件 → 动作目的 → 函数 → 参数 → 最终形态

本页是实际画线入口。输入是原曲观察与目标音乐／音素条件，输出是Agent独立设计的稀疏参数。研究解释和生成决定分开；不给曲名、字名、时码、作者profile或六类角色标签建立参数查找表。

## 先把当前段读成条件

确定一整句的音乐身份与落拍，再逐元音标出：当前及下一主音；字内转音的有序音符；辅音／元音／韵尾；主音到达；可用持续段；下一字或AP/SP；歌词重心、重复句关系、目标音区和已选声线。原曲F0说明实测运动及unknown，GAME说明候选记谱；两者冲突先查八度、混声、分离残留、字界与音乐中心，不能自动平均成目标。

把源事实、工作解释、主动选择分列。一个实际决定至少能回答：此段要清晰落音还是舒展进入？主体是在维持、回收、展开还是让出？动作在哪段存在，为什么备选不合适？什么观察不足？参数怎样使这个顺序出现？时长只限制容量，不代替以上判断。

## 函数选择

| 当前条件与目的 | 函数设计 | 需要明确的参数 | 反例／拒绝条件 |
| --- | --- | --- | --- |
| 下一音要在落拍清晰成立，或主体很短 | 单次单调中心连接；可用quintic或有导数Hermite | 离开、到达、前后绝对中心、衔接斜率 | 柔进入不必把主音提前；不能吞前字主体 |
| 大上行需要舒展进入，且有实际元音容量 | 两次连接＋短承接，承接可有慢走势 | 中间高度、到达／离开承接、最终到达；相邻导数 | 相同时长也可清晰直达，音程大不自动选台阶 |
| 起音应先准备、回收或短过冲 | 有符号的有限弯折，或中心路线中的有序转向 | 离开、峰／谷、恢复；幅度和升降耗时 | 起音不等于每次低头；主线上行可吃掉负弯折 |
| 中短承接需要带出、轻抬再收，不宜持续摆动 | 单个／少量有限回收，允许不对称时间 | 每次支撑、极值、恢复；邻接是否零斜率 | 短字也能有明显波，不能以短时长直接给平台 |
| 稳定主体要留住但不持续周期 | 中心Hermite慢走势、有限浅回收，或明确常值 | 中心转向、局部耗时、实际cents幅度；保持理由 | 克制不必只有3c；长音也能有展开，须看整句层次 |
| 主体需要持续动态支撑 | 相位积分的周期＋独立深度包络；必要时自设计不等时峰谷 | 进入／退出、深度轨迹、Hz轨迹、相位、中心、峰谷非对称 | 原曲无可靠周期仍可主动选；不是全长正弦或所有尾字默认 |
| 长主体要先留住、再展开、回收后继续 | 多阶段中心／有限动作／周期组合 | 各阶段实用支撑、存在与停止、再进入；衔接条件 | 不是把一条作者包络循环，不能统一“后半才颤” |
| 同元音跨音符换主音 | 连续中心路线＋不中断的调制相位 | 每次音乐到达与阶段中心、周期支撑归属 | 不能逐音符重起，也不能用一个去重tone列表决定末音 |
| 同音但换字需重新咬字 | 保持音乐中心，另选有限发音动作或控制 | 声母／元音锚点、回收支撑、控制响应 | 同音连元音不重新咬字；不每字固定下探 |
| 准备后字、收句或进入停顿 | 释放中心／有限动作，周期独立渐隐；另定非唱段 | 释放／恢复、下一字关系、AP/SP两侧基底 | 不拖长最后半波；非唱载频不是唱音中心 |

这些是条件下的选择空间，不是完整自动分类器。按当前整句排除不合适分支后提出可执行首版；不把不确定性作为回避设计的理由。数值起步见[条件配方](conditional-drawing-recipes.md)，真实接口见[上下文执行](context-execution.md)。

明显转音与承接按[转音与支撑推断](expressive-turn-and-support.md)另定较大动作预算。记谱中心连接加一个小`0→A→0`，不自动表达回探、跨目标回收或再次到达；所有字都必须有鼓包、途中节点都必须零导数也是错误限制。

## 数学与组合

将绝对目标写为 `C(t)=M(t)+B(t)+P(t)`：M是设计的音乐中心路线，B是有限偏差／慢走势，P是周期。曲线全部由当前参数产生；原曲数组和作者数组不作隐含基底。发声及输出包络另通道，不用音高振幅代替响度。

- `Q(u)=10u³−15u⁴+6u⁵`，u为当前段局部时间；可用`a+(b−a)Q(u)`作零端导数连接。它适合真正的停留／转向端点，不宜把所有单调途中节点都做成停顿。
- C1 Hermite使用两端值和实际cents/s导数。连续单调中心应保留恰当导数；极值可为零。自行选节点，不从参考稀疏化产出。
- 有限回收分两段连接`0→A→0`，峰位置与升降耗时独立。A可正可负；与M相加后必须核对实际先升／先降是否存活。非零导数衔接应设计到中心，不能硬拼两个不相容支撑。
- 周期`P(t)=E(t)A(t)sin(phi0+2π∫f(s)ds)`。深度A、有限包络E、Hz和中心分别安排；同元音相位连续。变速不能用f(t)×t；退出包络收幅度，不拉长末半波。需非对称或不等时波时，自定稀疏峰谷和斜率，不能从别人样本提取后改名。

每个阶段都先声明预期存在区、局部幅度、转向／到达次序；随后才计算。所有节点有目标原生锚点。检查局部期待的区域而非全字总音域。若需要可见展开，幅度预算根据该段音乐意图及用户尺度提出，不能靠扩大纵轴证明完成；平稳反例允许单独小范围或常值期待。

## 设计辅助工具的契约

`scripts/design_functions.py`只消费一个独立设计空间的JSON：

- `schema:1`，`origin:"agent_designed"`，`support_s:[a,b]`，时钟由调用者声明并绑定当前目标。
- `center_nodes:[[t,absolute_cents,slope_c_per_s],...]`，严格递增并覆盖a至b。
- `components`：`finite_return`具有id、support_s、peak_s、peak_c；`oscillation`具有id、support_s、attack_end_s、release_start_s、depth_nodes、rate_nodes、phase_rad。节点为`[seconds,value]`并覆盖组件支撑；深度为非负cents，速率为正Hz。
- `decisions`：按序覆盖全支撑，每项有support_s、condition、choice、alternative、reason、uncertainty、component_ids。平稳仍有决定，可以没有组件。
- `expectations`：support_s、range_c:[最小,最大]、purpose，核对最终线在指定局部的幅度范围；这些数值是当前设计期待，不是通用质量门槛。

用`--plan`、`--out`和可选`--step-s`运行。程序检查参数与覆盖，按Hermite／quintic／相位积分计算，保留失败结果。只支持有限子集；不读源音频、F0或作者文件，不生成USTX，不自动处理phones／AP/SP、非对称周期或声学依赖。origin只是声明，不能程序证明参数未抄袭；还需检查调用者代码和输入哈希。范围检查也不能代替有序极值、音乐判断或听感。

## 转到原生工程

设计的center_nodes转为实际锚点的melody_nodes；有限回收按真实签名转为local_gesture或自设计body_landmarks；周期按实际条件转为dynamic_periodic或自设计的periodic_landmarks。不能假定辅助工具JSON与schema3可以直接互喂，不把密集采样结果当参考点拟合；适配器必须保留函数、支撑、单位和期望。相位／包络表达不足时补接口或明确unsupported。

当前原生`local_gesture`使用三次smoothstep，此辅助工具的finite_return使用quintic；当前`dynamic_periodic`是线性深度／线性Hz与三次包络，此辅助工具支持多节点quintic深度。相同节点参数不会产生同一条线。若选择现有原生函数，从设计开始按它实际的三次公式检查；若已选择quintic／多阶段深度，需补相应接口并证明最终线，不能宣称直接转写就精确实现。中心Hermite可按值／导数对应，仍需实际时钟核对。

原生连接、非唱边界与不同采样起点按[连续线检查](continuous-contour-and-scale.md)核对。函数C1不保证note基底＋PITD在应用里C1，采样一致不保证网格移动后无针尖。整首每个阶段的条件与实际函数均须可追溯，数量覆盖和数学执行通过仍不能宣布表达能力。
