# 表达计划与自动评估约定

虚实连续性任务须按[虚实走向](phonation-continuity.md)记录全部短句的基底、连接字的保持／补偿、发音保护、实际预测与最终输入。仅对照写入控制不足以完成此项；统计更一致不是听感接受。

整曲显式目标接口见[whole-song-redraw.md](whole-song-redraw.md)，局部旧接口见[pilot-execution.md](pilot-execution.md)。本文件其余字段是扩展计划契约；执行器未实现的字段必须保持planned或unsupported，禁止在输出中称其已经作用于工程。

## 计划结构

先按[条件到函数](source-condition-to-function.md)记录当前源条件、备选、实际函数及本段参数来源，不读取作者数组作为生成目标。建议保存expression_plan.json，绑定原工程、源音频、谱面、歌词、声库、模型与工具版本哈希。包括整曲风格意图／声线基底、段落与重复关系、全部乐句计划、控制预算和评价声明。

乐句计划记录phrase_id与实际输入身份、前后context、音乐角色、可靠观察和推断。每个动作记录：

- target：原note／word／phone的稳定ID，不以歌词字或裸时间作例外键。
- anchor：相对谱面／元音／乐句的锚点及单位，明确源与合成时钟。
- action与parameters：具名函数／控制，稀疏参数、实际单位与有限支撑；可含body／vibrato／entry／transition／release／gain／phonation等意图。
- intent与evidence：希望改变的演唱行为、输入依据、观察／推断／策略选择的区分及不确定性。
- expected_effect与dependencies：可检验变化、可能副作用、需要更新的pitch／speaker／variance／DYN依赖。
- execution_state：planned、compiled、rendered、automatically_checked或unsupported。

每个输入乐句都应明确计划，不允许静默漏覆盖。局部编辑可写有依据的keep_baseline；用户要求整曲全部绘制时，只能明确写新目标（可以是平稳主体），不能用keep_baseline沿用未规划的旧曲线。控件支持、参数范围、单位转换和锚点解析由执行器验证；按实际使用的整曲或pilot接口核对。获授权的转音重新诠释需另列GAME记谱与主动演唱目标的差异及理由，不伪装为源事实修正。

画法决策参考baishuo-drawing-method.md及当前用户允许使用的项目研究证据。补齐字头到达、同音换字／连元音、局部准备／回收、字腹、周期支撑及尾字关系；不要让每句只有一句语义描述和一组join/body/vibrato常数。动作计划要记录具体锚点与形态、原例支持还是艺术外推、可否被当前执行器表达。所选动作被单一连接／字腹模板吞掉时保留unsupported；覆盖完整、C1或F0误差很小不提供表达验收。有限模板执行只能提供技术基线，不能作风格成功示范。

## 自动评估

遇到反复平直的问题，执行[整句尺度与字腹运动](phrase-scale-contour-study.md)的双尺度审阅：完整整句的统一秒／半音比例图册、全部元音阶段账本、明显波／浅波／克制反例的细图。未选周期的字也需审阅有限运动，不能只检查周期名单。图册和字段是可审阅产物，均不自带自然度判定。

细部画线按[microexpression-and-acoustics.md](microexpression-and-acoustics.md)核查入口次序、浅／深区域、中心走势、逐周期峰谷关系、起尾部分波和音素衔接。观察事实、声学机制假设、所选处理和预期可听变化分别记录；文字解释不算执行，局部平均值不代替这些完整序列。

在生成前分清完整性条件与表达比较目标，保留已有原SAFE／对齐门槛。完整性包括：歌词／音符身份、时钟／顺序、原生范围、实际F0执行已声明的目标线、覆盖与未知账本、渲染成功、状态／增益的条件来源。不得为听感意图修改源可靠掩码或旧实验判定。

时长／换字反馈执行[rhythm-and-syllable-duration.md](rhythm-and-syllable-duration.md)：对每字记录目标音乐时值、全部延续音、实际元音支撑、尾部与后字边界，以及相对独立节奏证据的偏差。时钟拟合与逐字节奏验收分开；拟合总体偏移不接受任何单词边界。动作支撑被压缩、后字过早和下一字反常变长是审阅提示，不是统一拉长比例。

表达比较可看进入／恢复是否符合计划、实际高音轨迹、句内能量意图、相邻句／重复句的声线变化。必须在匹配伴奏、一次整曲参考增益与可控制随机条件下比较；指标改变只代表该量改变，不直接证明自然度。不能用源F0误差减少取代上述多维评估。

若有实际可用且能力经过核查的音频模型，记录其输入片段、上下文、评价任务和不确定性；否则audio_perception_checked=false。文本Agent自评、技能结构验证和频谱代理指标不等于音频试听或自然度验收。

收到真实用户听感后，按确切交付音频哈希记录局部偏好／整曲接受及对应配置。`full_song_user_accepted=true` 与 `audio_perception_checked=false` 可以同时成立：前者来自用户，后者说明Agent没有自动听觉检查。保留历史报告当时未接受的状态，追加最新反馈；不以未消除的RMS落差否定用户接受，也不把一次接受扩张为跨曲通用验证。

迭代次数和渲染范围事前声明。初始试点最多两轮策略修订；每轮要关联修改前假设与修改后结果，保留基线和失败候选。不能按同曲参考曲线选优、在保护集上反复选模型或无限增加自由度。人工音频审核不作为运行／交付前提。

交付工程／音频时可标记completed_with_warnings，明确自动完整性通过范围与尚无独立音频评价；不要把不确定性转成必须等待人工的批准流程。未生成实际工程／音频的阶段只交付计划与设计，不冒称渲染候选。
## 非 pitch 与长音阶段的补充约定

按[多通道发声与长音阶段](joint-phonation-and-sustain.md)，每个实际元音分别记录音高阶段与发声／输出包络阶段。非 pitch 通道必须有实际稀疏节点或明确保持理由，不能以全曲统一的默认 phonation 标签替代判断。每个包络绑定真实锚点、单位、基底和恢复范围；单因素原生输入对照与最终听感分别报告。接口合成探针通过不等于歌曲已重新渲染。

## 独立设计的追溯

低转高不自然的修订按[上行音程衔接](upward-interval-connections.md)保存全曲相关边界账本，包括选择保留的快速反例。记录前音可用支撑、声母／元音锚点、离开与主音到达、10%→90%耗时、途中导数和旧主体处置。核对生成代码实际消费这些独立参数，不能仅以Skill新增了规则宣称现有连接已经更改。

用户指出转音保守或支撑乏力时，按[转音与支撑推断](expressive-turn-and-support.md)核查实际动作族分布与理由：全字同类鼓包、近乎统一短直达、无承接／回头不能由“独立手写”证明合适。局部受控对照和全曲生成分别报告；没有听感证据不能以技术通过选出更自然的版本。

生成输入分别列为源观察、目标原生时钟／声库、Agent设计参数；作者资源仅列研究来源。核对实际调用代码没有加载作者曲线、profile或旧目标；origin声明不是未复制的证明。每个阶段有当前条件、备选、函数、参数和局部期望，审阅理由与数值是否一致。固定尺度全部阶段审阅与原生边界／相位检查分别记录，不能只用设计工具的局部幅度pass代替完整检查。
