# 条件画线配方：台阶上行与稳定音起伏

用于需要回答“提前多少、抬多少、每秒几次、幅度多大”的实际画线。以下是已核实参考形态归纳出的**首轮候选参数**：Agent根据当前音乐功能选路线，再带数值执行。它们有参考依据，但不是所有歌曲或声库已试听验证的普遍定律。实例和原始统计留在项目研究记录；本页不按歌名、歌词、音符ID或时码分支。

先按[条件到函数](source-condition-to-function.md)决定动作存在区与目的。下表不是依据时长、音区或六类角色直接派发参数的分类器；不能读某个作者实例的数值序列填入新目标。参数由Agent根据当前条件自行设计。

## 单位与时间零点

`L/H`是前后音乐主音的绝对cents，`Δ=H−L`；100c为一个半音。`V0`是新字实际元音开始，不能用辅音开始或谱面边界代换。周期频率`f`为Hz，周期秒数`T=1/f`。生成用单边音高幅度`A`：围绕中心的±A，峰峰范围约2A；它不是响度。参考保守半峰谷只是A的初估，非对称峰和谷仍分别安排。

## 上行先决定直接到达，还是两段承接

用户反馈上行生硬时，补读[上行音程衔接](upward-interval-connections.md)：直接／承接之外，同元音连续推进需要保留途中速度，且必须复核旧主体与新到达时序。下表给候选范围，不授权把全部上行用同一短S曲线或仅按音程改一个时长常数。

**推断的用意**：直接到达让新音在节拍／重音处明确落下；两段承接把“开始唱新字”和“完成高音展开”分开，使入口先有落脚点，再把剩余音程唱上去。中间台阶通常靠近目标而未完全到达，更像持续过程中的短承接，不像新增一枚固定的旋律音。因此用`H−r`定位台阶比“永远从L升一个半音”更符合观察。这个解释指导候选选择，不假称作者意图日志或发声生理结论。

| 当前条件 | 首选路线 | 原因 |
| --- | --- | --- |
| 新音短促、下一换音很快；或需要节拍处清晰落音／突出重音 | 直接到达，即使音程大也不强加台阶 | 台阶占用字腹，可能造成迟到与含糊 |
| 上行约3–9半音，新字首个目标音约400ms或更长、实际元音至少约220ms，音乐需要舒展／拖入／渐进 | 两段承接作为首轮候选；另保留直接路线作对照 | 有时间容纳入口、短承接、二次上行和主音主体 |
| 目标短于约400ms或元音可用支撑不足 | 默认直接；特殊拖入须有明确音乐依据并重新分配时间 | 当前参考中短目标的台阶支持弱，不压缩复制长入口 |
| 同一个元音内有已记谱的经过音／分段主音 | 先保留真实主音顺序，沿音乐路线连接 | 不能把真实中间音当装饰台阶删除，或每个延续音重咬字 |
| 需要强而明确的高音起头 | 优先直接；若选台阶则缩短承接、确保及时落主音 | 大音程本身不意味着应柔化；音高动作不能替代张力／声线支撑 |

400ms和220ms是选择提示，不是硬截断；前后音程、实际元音与音乐落点优先。参考中满足时长也有直接上行，时长并不单独决定路线。

### 直接上行的数值候选

把主要上行放在元音前约50–130ms，元音前后约±20ms进入目标附近；主要10%→90%音程段可先取35–100ms。用于清晰起头时从较短一侧选，用于柔连接时从较长一侧选。入口若已偏低／带准备，另画准备再上行，不把整段塞进统一S曲线。

具体起始点依前字主体和后字辅音支撑确定，不能为提前上行吞掉前字。辅音可能有声，不能自动当静音隐藏错音。上述时间是主要运动段的候选，不表示所有起音应在谱面前等长开始。

### 两段上行的数值候选

| 参数 | 上行3–4半音 | 上行5–9半音 |
| --- | --- | --- |
| 中间高度 | `H−100～210c`，即仍低于目标约1～2半音 | `H−130～200c`，通常完成总音程约70%～80% |
| 第一段主要起升 | `V0−90～−20ms`附近 | `V0−125～−35ms`附近 |
| 进入承接段 | `V0+0～40ms`附近 | `V0−15～+25ms`附近 |
| 承接时长 | 约45–90ms | 约60–170ms |
| 第二段主要上行 | 约30–75ms | 约25–65ms |
| 进入主音附近 | `V0+105～170ms` | `V0+120～225ms` |

这些是分别观察到的局部范围，**不能任意组合各列极值**。先定主音到达时间，再反推第二段、承接与第一段，保证所有节点严格有序，留下可辨主音主体。中间可慢行或有浅回收，并非必须画绝对水平的平台。承接段比最终到达通常早约100–200ms；这与“在元音前提前100–200ms”不是同一件事。

一个可执行的初始设计：上行7半音、需要舒展且支撑充足时，台阶取`H−150c`；从`V0−120ms`附近离开旧音，在`V0+15ms`到台阶，承接到`V0+115ms`，在`V0+185ms`到H。其中离开旧音的完整节点是对主要起升观测的设计扩展。先核对真实音素与音乐落点；需要节拍上立即落高音时改选直接路线，而非等用户指出迟到才处理。

编译用`melody_nodes`绝对主线记录旧音保持→台阶到达→台阶离开→H到达。台阶不新增歌词，不移调整个字，不改源事实。最终线要看到二次上行与可辨承接；其它body／periodic叠加后也需核对。如果成了一个缓坡或把H主音唱没了，就没有执行这条配方。

## 稳定音：速度相对集中，深浅和阶段更能区分画法

**推断的用意**：稳定音的周期提供持续的动态感；深度展开使支撑更显著，收浅给下一动作腾出空间。明显周期的速率相对集中，表现强弱主要通过幅度、存在区域与发声条件组织，不能把“加强”简单改成更快抖动。浅小折返混有不规则运动，不能将其所有峰间速度等同于稳定颤音。

| 音乐条件与动作 | 首轮频率／间距 | 首轮单边幅度A | 使用方法 |
| --- | --- | --- | --- |
| 稳定音需要普通、可辨的周期支撑 | 约5–6.3Hz，周期约160–200ms | 约15–35c；先试20–30c | 从主音到达后的可用字腹选择支撑，整句不只挑尾字 |
| 克制、较轻的字腹需要浅运动 | 若选重复浅波，可试5–7.5Hz；也可选单次回收 | 约3–8c | 只有音乐确实要求收住时使用；有限回收无须指定周期。用户要求主体明显展开时不能以此浅区间代替判断 |
| 持续音需要较明显展开 | 约5.2–6.3Hz | 约25–45c | 先浅后展开或中段展开，深度可回收，不自动重复到字尾 |
| 明确高潮／重情绪的持续支撑 | 约5–6.5Hz | 约45–65c作为较深候选 | 单独核对中心、音准和发声；不是每个高音的默认值 |
| 中短元音需要有限显著起伏 | 约5.3–7Hz可容纳少量波；或选择单次弯折 | 约15–40c | 看实际可用段，允许起尾部分波，不凑完整周期数 |
| 普通承接字只需轻抬／回收，不宜连续抖动 | 不指定周期；有限动作可先试80–180ms | 相对音乐中心约10–25c | 这是从短字起落提出的设计候选；给离开、转向和恢复节点，支撑不足则减小或取消，不自动铺平台 |

常规起步可用约5.6Hz、A25c；这只是选定“普通周期支撑”后的一段初值，**不是每个字通用波浪**。速度通常无需随音符绝对F0同比增加；依据音区改变发声与音乐中心，周期速度仍用真实秒数。慢中心漂移与周期另层处理。

### 阶段规则比单个常数更关键

- 陈述后展开：入口到达／小回收 → A约3–8c的浅段 → A约20–40c的明显段 → 释放时减深或停止。不要把“浅段”替换成全字恒定零线。
- 先集中后让出：主体可较早采用A约20–40c，随后减到约5–15c，再接下一字；不要求一律从零线性增深。
- 长支撑可交替展开和收浅。进入时间由主音到达与音乐功能确定，不能把固定全字百分比当规律；观察中明显段既有早进入，也有延迟约半秒或更久的情况。
- 同音同元音延续保持相位；同音换字则另定重新咬字动作。退出可保留部分波，不拉长最后半波填满时间。
- 上下耗时与上下偏差分别选。有自然的有限偏差即可，不强制每波等时等幅，也不随机抖动；峰→谷耗时可从约周期的40%–60%试起，依具体回收方向改写。

`periodic_landmarks`适合不等时、不等幅的稀疏峰谷；`enveloped_periodic_landmarks`接独立进入／退出包络；`dynamic_periodic`只用于可以由简单变深变速表达的一段。频率变化按积分推进相位。函数执行数值，Agent仍负责条件选择和阶段衔接，见[上下文执行](context-execution.md)。

## 规律怎样用于下一首歌

Agent先读每句旋律／节奏、重音落点、歌词发音与实际元音，主动决定清晰落音或拖入、克制或展开、保持或让出。然后从上述条件区间选数值，写出锚点和理由；没有持续周期的字也选择有限动作或明确平稳。不能要求小白用户先指出每个规律和位置，也不能根据听感尚未验证就拒绝提出可执行初版。

输出前按[整句尺度与字腹运动](phrase-scale-contour-study.md)核对最终整句与细图：台阶高度与时序、主体运动的实际存在区域、局部峰间秒数和音高幅度。统计归纳帮助起步，逐项形态检查确定执行；没有把长段中位数或配方落在区间内当成好听证明。之后用确切音频反馈调整条件规则，不改成歌词特判。

## 区间不替代主体期待

分别声明主音到达、真正维持、展开、回收和准备的局部范围。主体期待只在该支撑检验，不以字头／出口的大运动填高全字总音域。首次数值选定后计算实际函数，检查转向及存在区；若整体仍同形，重查条件判断与函数，而不是仅把表中幅度提高。
