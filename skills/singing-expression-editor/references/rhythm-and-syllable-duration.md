# 节奏先于音素映射与画线

适用：唱得太急、该拖的字短促、下一字提前、字内转音加速；也用于新转谱／HFA 后的整曲准备。音高曲线即便正确跟随目标，目标时长错了仍会唱错节奏。不要先增加颤音、张力或逐字音量。

## 三个时钟和证据权威

分开记录：源 HFA 声母／元音观察、所选音乐谱面（起拍、延续音、字尾、下字）、新工程原生音素时钟。源 HFA 不等于正确音乐节奏，原生 phone 也不是完整的旋律身份。相邻相同／相近韵母、无声母起字、分段上下文重叠或右边缘截断都可能让 HFA 把前字持续部分归给后字。

先选择音乐节奏依据：用户授权的同曲参考谱面、可信乐谱或审阅过的 beat／note 骨架。GAME 和音频发音证据可支持或质疑边界，但一次 GAME 变音不是换字证据。无独立节奏依据时，先扩大整句上下文、联检前后词、辅音与拍位；无法确认的时长保持 unresolved，不能从“全字都有正时长”推出正确。

同曲参考可提供完整节奏目标，但作者工程与录音必须先核实是同版本／同速度。利用跨段分布的独立音乐事件验证录音时钟：明显旋律换音可与 GAME 的同目标主音换音对应，发音可靠的 HFA 起点作另一组对照；不得用反馈指出的错边界自行选择偏移。明确全局平移／速度关系与各段残差；恒定平移不成立时审阅速度、版本或匹配，而非逐字扭曲时间来掩盖。伴奏始终保留录音时钟。`rhythm.py` 的中位数仅用于时钟初估，各区域和每字仍独立核查，不能用于风格或边界验收。

## 整句联检与修正选择

逐字查看全部音符和延续音，不把多音符字拆成多个发音起点。记录预期元音可用时长、稳定主体和有意义的尾部；一起查看后字声母／元音起点、拍位及其时长。前字明显变短、后字相应变长／提前，或整条参考转音被挤进很短区间，要审阅这一对和完整乐句。重复段提供独立的同类问题对照，但不能因歌词相同自动复制局部操作。

修正的是错误的换字分配或明确选择的新音乐目标，不能用固定倍数加长所有长字／尾字，不把某个字或时间戳写成复用代码特判。默认从当前录音的音乐证据选择字界与延续，研究参考时保留两边节奏差异，不直接把作者时钟用作生成目标。只有用户另外明确选择参考节奏时才迁移并声明依据；其它曲目的偏移、时长和阈值不能套用。

边界／音符时值变化后重建 AP/SP 空隙、重新导出目标音素、完整编译 pitch／PITD，重新映射已选动作锚点，更新 variance／acoustic 条件并渲染。声母预备可以在音乐起拍之前，但不得借此偷走前字主体；元音持续经过多音符时不重复起声。周期 Hz 继续按实际秒数积分。

## 验收和反馈

同时检查完整字与后字：谱面时值及续音是否执行、实际元音是否保有完整持续段、下字是否在选定位置进入、参考动作是否被压缩。保留全部局部序列；正时长、不重叠、整曲覆盖、总体 tracking p50 或自身目标误差小均不接受错误的节奏。

可调用的波形检测器只能提供音高／能量证据，不能可靠分辨相近韵母的字界；保留 unknown，不用检测器证明唱字边界正确。对照音频固定声线、伴奏时钟及全局混音条件，直接截取上下文。取得用户真实听感后按该音频 hash 记录，不先宣称所有同类问题解决。
