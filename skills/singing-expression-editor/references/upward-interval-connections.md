# 低转高：连续推进、承接与短促到达

用于上行大跳显得生硬、转音不连贯的反馈。先绑定当前音频，列出全部相邻唱音和同元音内上行音乐阶段；非唱载频与跨停顿起音另列。分别记录音程、前音可用尾部、真实声母和元音、下一次换音、重音落点、旧连接的主要运动时长及到达时间。不能以函数C1、目标跟随误差或移调正确反驳听感。

## 连接不只是一条较长S曲线

完整运动包括离开旧音、第一次推进、途中速度变化、进入目标附近、稳定／恢复。先决定哪部分能提前，哪部分必须在新元音中完成。大音程不自动要求拖到高音后才起升，也不自动允许把前字尾部全当准备；前字仍在承载含义或已有主体动作时，保留它的支撑。

| 当前条件与目的 | 可独立设计的路径 | 反例与限制 |
| --- | --- | --- |
| 舒展的新元音，有足够主音主体，入口需要先落脚再展开 | 先进入目标下方的承接，再缓行／浅回收，最后推到主音 | 短字、强落拍或下一换音很近时，承接会吞掉主体；不用时长阈值自动派发 |
| 同元音内已记谱上行，需要保持一口连续运动 | 单调或带明确回转的多节点中心；途中保留非零导数，到主音才稳定 | 每个中间节点都用零斜率会产生多次停顿；不能新增咬字或抹去真正经过音 |
| 短促大跳／经过音，需要清楚落音 | 主要运动提前准备并快速完成；若音乐需要，可轻微过冲后回收 | 大跳也有快速直接的反例，不能一律慢滑；过冲不是默认，不能使主音始终未站住 |
| 前字与后字都需要明确主体，空间不足 | 限制准备长度，选择及时到达；必要时明确重新判断装饰音与主音的音乐解释 | 不通过偷偷移动字界、删音或改变歌词换取曲线光滑；主动改音乐需声明 |

承接的位置用`H−r`描述，`H`为目标主音，`r`是Agent独立选择的剩余音程。承接可以缓慢移动或浅回探，不必完全水平。既有[条件配方](conditional-drawing-recipes.md)可给首轮数值，但各时间区间不能任意拼极值，也不能成为按音程／时长选作者路线的程序。

## 数值要表达速度与到达

以实际元音开始为零点，分别设计离开、承接、再次推进、主音到达。除总时长外，记录10%→90%音程的耗时和最大／集中速度；它们用于比较本轮动作，不是自然度门槛。把9半音和2半音都压进同一短支撑，会让大跳的速度显著增大；仅增加采样密度或让端点导数为零并不解决它。

有限候选可从以下范围起步：舒展承接的完整连接约180–360ms，主音在元音开始后约100–230ms到达；同元音连续上行约100–260ms，按前后真实音乐阶段压缩或展开；短促清晰上行的主要10%→90%段约40–110ms。剩余音程、声母可用区、前音支撑和落拍优先，不把这些值视为全曲常数或统计验收。特别短的阶段可以保留直接路线；若它仍显生硬，重新查原曲音乐解释，不自动无限拉长。

使用`scripts/design_functions.py`的有导数Hermite中心可表达持续推进。途中导数按相邻割线限制，避免非意图的回头或过冲；真正承接、极值、主音到达可设零导数。分段Q5只适合确实要停留／转向的节点。原生note pitch先承担连续音乐基底，再依据新before-PITD编译细部；参数相同的Hermite与原生IO不等价，要检查实际复合路径。

## 连接与字腹是同一条最终线

新的主音尚未到达时，旧主体鼓包、回探或周期可能提前叠上来，导致中途多抖一次、刚到达就反向下探。逐段选择保留、换支撑、提前退出或延后进入；不能只是把新连接覆盖在旧曲线上，也不能统一清空所有主体细节。延后周期时重算物理相位与进入／退出，保留真正经过音的音乐顺序。前字尾部仍在发声时，准备音高与其旧周期也要一起审阅。

全曲相关条件分别选择处理和反例，并在同一秒／半音尺度检查完整低→高跨度及局部细节。检查实际唱元音中的起升、主音是否留有稳定支撑、下一转音是否挤入、AP/SP接口是否被侵入。原生读回与实际相位探针各自保留；技术跟随通过后重新进行音高依赖的两阶段预测和音频合成。对比片段匹配伴奏、speaker、音素、随机条件和公共增益，避免以响度差冒充衔接改善。

研究工程揭示的是书面运动及当前原生路径，不能证明历史声音或作者心理。跨音素的大下探、下一字准备、八度冲突与无法确认的载频跳变不能照搬成低头配方。作者节点、数组和局部曲线留在研究档案，生成只消费当前条件与Agent自己的参数；用户试听验收另记。
