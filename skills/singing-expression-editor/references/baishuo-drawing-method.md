# 从参考观察归纳条件判断

研究流程见[原曲／作者资源](reference-imitation-calibration.md)，生成见[条件到函数](source-condition-to-function.md)。原曲提供音乐与细部观察，作者工程提供可观察的处理；作者意图只能是假设。Skill不发放作者曲线、profile或逐字卡包给生成器。

逐段先识读绝对中心、note pitch、before-PITD、PITD、最终线、原生phones与非pitch控制。内置vibrato为零不说明最终线平直；书面控制不证明历史声音、气声或响度原因。

研究六方面，但不把它们做成六类参数派发器：字头到达与前字关系；换音的离开／承接／到达；主体有限回收与慢走势；周期存在、深浅与退出；下一字／停顿准备；同元音有序转音。每个方面均联检实际音乐中心、音素支撑、落拍与可用时间，找到相似条件下不同处理的反例。

归纳条目写为“当前观察条件 → 候选处理 → 可选函数与必要参数 → 反例／应改选条件 → 最终形态核查”。不能只记录作者哪里有峰谷、平均深度多少，然后依据时长选择最像的一条。数字区间作首轮设计范围，函数节点由Agent自行设定；没有持续周期的字也需要判断有限运动或明确平稳。

计划转为真实接口后分别核对：条件是否适用；函数是否能表达所述顺序；参数是否实际消费；最终叠加后是否存活；实际声音是否被接受。覆盖、原生跟随和解释文字不能代替其中任何一项。整首固定尺度审阅见[整句尺度](phrase-scale-contour-study.md)，多通道选择见[发声与长音](joint-phonation-and-sustain.md)。
