# 转音动作与发声支撑的推断

用于用户反馈“太保守、转音没起伏、发音怪或有气无力”。先绑定被听到的音频及唱字，不将自己的目标跟随误差或曲线数量当作反证。以下是参考条件的工作解释和独立设计候选，不是已知作者意图或自动风格分类器。

## 先判断运动属于哪一层

1. 记谱主音变化：保留按时序排列的主音与音乐支撑。
2. 演唱到达与装饰：主音前的承接、回探、过冲、跨目标回收、提前释放。它们可占一个或几个半音，不能套用小颤音的幅度预算。
3. 主体微波与周期：围绕当前中心较浅或明显的运动。它们不能替代尚未设计的大转音。
4. 辅音、韵尾、下一字或非唱载频：先核实归属，曲线在字窗末端的大跳可能已经准备下个音；不能把它当作该字应有的装饰。双检测器同意也可能共同错八度。

原曲可靠F0给出动作方向及大致发生区域；GAME是候选记谱。作者工程用于研究“同类条件怎样处理、何时没有处理”。生成时自定新的节点、耗时、导数及发声选择，不提取原例的峰谷序列。

## 条件、目的和独立函数

低转高显得突跳时，先按[上行音程衔接](upward-interval-connections.md)区分舒展承接、同元音连续推进和短促落音。检查10%→90%耗时、途中导数及到达后的主体，不将增大幅度或统一拉长视为修复。

| 观察到的条件与目的假设 | 首轮设计候选 | 拒绝条件与检查 |
|---|---|---|
| 元音进入后仍在主音下方承接，随后明确上冲 | 中心路径先承接／回探，再上行到达；分别给承接与主音到达节点 | 清晰直达的短字不强加低头；不能在辅音区用不可靠F0确定落音 |
| 大下行的同元音转音需要甩下去再站住 | 下行中心连接＋有限越过目标＋回收；保留真实主旋律次序 | 短承接可只直达；不把整个音程当周期幅度，不添加重新咬字 |
| 主音已到达却需要再转向、回探后重新撑起 | 多节点中心／有限装饰路线，有正负转向、承接、恢复 | 周期足以表达的稳定主体不增加大摆动；缺乏源证据时明确为艺术诠释 |
| 显著动作需要从上一阶段贯穿到下一阶段 | 有导数Hermite或分段平滑路径，途中节点保留非零导数 | 停留／极值处可以零导数；每个采样点都零斜率会把连续冲势切成一串停顿 |
| 主体已经稳定、局部作用是留住 | 明确的小回收、浅周期或平稳路线 | 这是反例；不能把少数克制例扩成整首默认平台，也不以全字强制鼓包证明判断完成 |

数字起步需要Agent主动提出。若原曲与音乐作用支持明显低位承接，可先设计主音下约150～300音分的承接／回探、约50～120ms承接和80～180ms再到达；较短或轻的动作减小或取消。大下行若需要越过后回收，可先试目标下约40～120音分、35～90ms转向支撑和40～100ms恢复。上述是针对这些条件的设计候选，不是统计验收区间，也不要求每次大跳越过目标。完整跨度还包含真实音程；不能将所有动作限制在“±几十音分”以求稳妥。

先声明局部的离开→承接／极值→到达次序、目标相对高度、每段实秒耗时与导数，再选择函数。已有center_nodes可以表达多节点中心；单个`0→A→0`只适合真正的有限回收，不能强制用来表达所有转音。动作若通过加法实现，检查最终线是否仍有预期转向，是否被主旋律抵消或变成错误上鼓包。若新增了音乐音级，明确标为主动装饰，不能冒称GAME记谱修正。

## 发音怪和有气无力分别查

核查真实声母、元音、韵尾、时长及边界，再看元音的音高进入、维持、离开。声母正确、时长合理也可能因元音过早到达、错误鼓包或短周期而产生怪听感。不能只凭拼音正确判发音已通过；也不能未经证据把声母时长改短。

检查实际speaker及新variance输出，再检查TENC／BREC／VOIC的叠加时序。默认存储控制不表示预测张力为零，TENC正值也不表示最终张力正值；预测值的单位不等于响度或气力。没有局部减VOIC／加BREC时，不能归因于人工气化。

长音仍在撑句或等待后字时，早期减张力＋增气声＋减发声成分可能与目标冲突。先判断主音／语义的结束是否已经发生，分别选择保留、支撑、回收与真正释放；不能因为“长、句尾、颤音变深”就自动联动三种减弱。支撑平台也是有效函数，不要求控制都采用先升后降的零端鼓包。

比较至少隔离有根据的候选因素：原样基线、仅改音高动作、仅改选定发声机制，必要时两者组合。相同speaker、phones、伴奏、整曲公共增益与随机条件；pitch变化重新预测variance。需要查音素时长或声线时另建因素，不混入同一对照。通过输入隔离与波形复现，只证明实验成立；哪版发音与气力更好仍由实际听感决定。

## 整首实施防止再次退回模板

审阅所有字内主音变化、明显上下行入口、回头及长支撑，并保留克制反例；不仅挑最长尾字。逐段给动作解释和数值能否实现该解释。若全部字都带同一种有限鼓包、换音几乎全是同样短直达、主体动作为同一公式只是换幅度，重查决策，不能以“手写参数、覆盖全曲、C1”辩解。

按相同秒／半音尺度查看完整大跨度与浅细节，分别检查动作顺序、支撑时序、音准、音素归属及AP/SP两侧。局部因素对照不算整曲重做；获选策略应用整曲时重新检查所有相关条件，不把某个字的节点时码写入通用Skill。
