# 整句尺度与字腹运动

适用：反复交付仍像直线、只在放大局部时看到波动、只给少数尾音加周期。先审阅整句的运动分布，再研究局部细节；不能先认定有少量非零波动就已解决。本文的处理按音乐条件选择，不按歌曲、歌词身份或时间点选择。

## 把两种尺度绑定到同一条最终线

读取原生最终绝对音高、before-PITD、谱面及实际音素时钟。以真实秒数和cents绘制连续整句视窗，统一每秒和每半音的像素数。长句分页，长字续页，不为装进页面压缩时轴，不按各自最小／最大音高伸缩纵轴。保留元音前辅音与后字上下文，但把非唱载频单列，不能把它的大跳算成字腹运动。

再对浅波和明显波各作局部放大，标明倍率。普通视窗回答“运动落在哪些字、字腹哪一段，是否只有尾部有线”；细图回答“是否有真实回收、速度怎样变、峰谷怎样接”。浅段在普通视窗不显眼不等于无运动；只有放大才显眼的微小变化也不能冒充原本要求的明显运动。比较须保留同尺度的正例和克制反例。

离线辅助工具为 `scripts/contour_viewports.py`，只画图，不选动作或评听感。输入JSON有 `curves` 数组；每条包含 `id`、严格递增且有限的 `times_s`、等长绝对 `cents`，可附等长 `before_cents`、`notes`（`start_s/end_s/tone/label`）与 `regions`（`start_s/end_s/label`）。以 `--input`、`--out`、`--window-s`、`--px-per-s`、`--px-per-semitone` 指定文件和显示尺度。生成原尺寸HTML/SVG图册及坐标元数据；默认值仅是显示设置。跨曲不能以输入ID触发表达分支。

## 先分开旋律、进入、字腹和出去的动作

具体首轮参数与条件选择见[条件画线配方](conditional-drawing-recipes.md)。双尺度研究应产出可执行的形态、时序和幅度候选，不止列检查事项；有依据的局部规律可以指导新设计，不能把“不保证普遍好听”误解为不允许给数值。

一个字可能覆盖多个记谱主音。先保留有音乐意义的到达／转向顺序，再看各阶段相对音乐中心的运动。整字音域不是颤音深度；升音途中一次弯折不是一个稳定周期。也不能把周期全部赶到最后一个音符，以便在恒定主音上容易计数。

进入前的反向准备、元音内下探／回收、字腹缓慢走势、反复波动、下一字准备可以相接，不能依固定时值比例划分。辅音起点、元音开始、主音到达和释放起点分别标出；同元音跨音符不断气，不按音符重起。相邻同音的新字则检查是否需要重新咬字的局部动作。

为**每个完整元音**作有序阶段账本：

| 当前条件 | 选择与执行 | 最终线核查 |
| --- | --- | --- |
| 中短字需要说出、带出或强调，持续周期不适合 | 选择有限抬起、回落、下探回收、单次波或直接到达；保留有目的的离开／转向／恢复 | 检查完整元音与邻字，不能因没有连续颤音自动铺平台 |
| 中短字有明确波动支撑 | 可选择少量完整波和起尾部分波；按物理时间执行 | 不以最低完整周期数硬门槛清除它；不为凑数挤入波动 |
| 持续字需要展开 | 决定浅运动、展开周期、回收的存在区域；深度、速度、中心走势分开变化 | 检查逐阶段覆盖和有序峰谷，不只核对总周期数 |
| 长字用于留白、连接或克制 | 保留浅回收／缓走势或明确平稳；持续时间不是深颤依据 | 同尺度与类似角色的克制反例对照，不为“看见线”统一增幅 |
| 波动存在但中途需收住、让字或换音 | 减深、停止或接慢走势，允许中间浅段后再次展开 | 参考序列结束后重新决定剩余段，不能延长末波或循环填满 |
| 音乐中心变化时仍需连续表达 | 先画音乐路线，再安排相对该路线的运动与相位衔接 | 同时看绝对线和调制分量；中心坡度可遮蔽极值，但不能以残差有波就宣称最终动作成立 |

阶段账本保存实际起止锚点、选择的动作、音乐目的、预期峰谷／转向顺序、幅度与时距、接入和退出方式、来源和不确定项。这里只定义审阅记录，不能宣称现有编译器已直接消费新字段；转写到现有动作接口后读回核对。没有依据的段落列为待决定，不以默认平台交付。详见[上下文执行](context-execution.md)。

## 学习的是顺序和形态，不是一组均值

对允许使用的参考，逐段记录浅深变化、各峰谷、上行／下行耗时、峰间秒数、中心偏移与第一／最后部分波。单一正弦不能表达不对称上行和下行；单一线性渐深也不能表达展开后收浅。稀疏关键点须保留局部转向，不能把每个量化折点当独立动作。完整字和整句上下文仍须核对。

自动峰谷候选可能混入到达过冲、音乐换音、尾部准备或量化噪声。相邻峰间计算出速率只说明这段几何间距，不证明生理颤音。判断持续周期同时看连续重复、中心是否稳定、谷的位置和音乐阶段。频率是运动速度，音高振幅是cents范围，两者均不是响度。

吸收技巧时为每个条件找一个处理不同的近邻反例：相似时值却克制、同一重复位置却改变退出、短字有波而长字浅。音乐角色与音素可解释选择，但只是待测假设，不能声称知道作者意图或在当前声库上必然好听。先用完整上下文的固定条件候选验证，详见[计划与评估](planning-and-evaluation.md)。

## 防止再次压平

长字被简化为平直中段加尾部波动，或显示中有音符边界针尖时，采用[连续画线与稀疏路线](continuous-contour-and-scale.md)。以用户原图的物理比例绑定整首，审阅点间显示与原生结果；不得只更新被点名长字、保留其余未重新选择的旧主体。

不要将整条源F0统一平滑、统一缩幅后当作Agent字腹设计。滤波对不同速率的衰减可能不同，后续稀疏化又可能删掉转向；即使数组非恒定，也可能已失去目标运动。确需去噪时单列目的、所保留结构、滤波前后局部幅度／时距／转向及当前采样分辨率，不以“更平滑”验收。源未知段维持未知，不用补波冒充源事实。

完整图册、所有元音阶段账本和明显／浅小／克制三类细图应在整曲渲染前可审阅。把未计划平台、运动存在区域错误、关键转向消失、幅度被压到不符合所选动作的段落列为问题；不能只审阅挑出的周期字。允许平稳的段落需有当前目的及实际衔接，并与遗留未规划平台区分。

生成后逐项比较计划和原生最终线。平均频率、非零变化、覆盖率、波动数量、整曲中位数及跟随自身目标只用于各自技术检查，不能确认已学会或听感改善。改变pitch后重建声学依赖，按固定声线／混音与随机条件试听；没有音频感知时只报告曲线和执行证据。

## 声学依据的使用边界

研究将演唱F0分成旋律过渡、过冲、周期和细小波动，支持分开审阅这些成分，而非把一切凹凸当颤音。它不能证明某条原生控制线的历史声音或作者动机，也不授权为人味添加随机抖动。[Saitou等的演唱F0研究](https://www.isca-archive.org/interspeech_2004/saitou04_interspeech.pdf)

普通话演唱研究把音高、音节内音素时长、起音、滑音、力度和音色共同考虑，提示动作应落在实际发声阶段；论文的简化时长比例和参数不作为当前声库默认值。[普通话表达性歌声合成报告](https://arxiv.org/pdf/1502.04300)
