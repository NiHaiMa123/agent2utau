# 突然小声与高音尖紧

适用条件：用户指出唱句内部突然小声、同一词前后出现差异，或用力后高音变尖、不舒服。先绑定反馈音频；实际能量、听感响度、音色和模型张力是不同事项。

相同人工控制下仍有落差，先按[音高、预测发声与响度](pitch-phonation-and-loudness.md)检查当前预测谐波能量、VOIC声明范围、音高的两条依赖及整句上下文。不要把VOIC=100误当固定基底或硬引擎上限；先选择发声意图并验证有限补偿，再决定剩余输出包络。

## 条件与判断

- 比较完整上下文中声母、真正元音核、词内连接、尾辅音、收句与换气。英文词的多个音节和尾辅音分别标出。短辅音空隙、滑向低音的释放、停顿、故意渐弱不默认是塌陷。
- 对全曲所有有效元音检查实际输出短窗能量、主体的早中晚段及邻字，登记保留／处理和理由。整段中位数或输入参数连续不能排除局部音量落差。
- 若已做整字检查仍被指出漏声，按[元音核与局部释放](nucleus-envelope-and-release.md)重查原始／最终包络、持续低谷与新气口造成的截短；已有规则没执行不能只靠再写一遍规则宣布修复。
- 在同音素、相近音区与类似音乐角色中比较，仍保留不同演唱意图。原曲分离波形含残留，粗对齐或unknown不能变成逐字响度真值；相对源能量只用于发现候选，不生成逐字归一化。
- 高音尖紧同时检查谱面与实测F0、实际speaker、真实元音、预测与最终发声输入。张力补偿持续撞高上限时，检查是否把“更有力量”错误实现为强制抬高张力；模型特征目标不是听觉目标。

## 选择函数

**音色过紧而元音主体能量并不低**：提出较温和的张力阶段，使用有限的进入、承托、展开、回收锚点，以平滑插值衔接整句。不要因为高音便继续加张力，也不以缩掉所有转音来掩盖音色问题。若实际音高、声线或辅音有独立错误，单独处理和验证。

张力曲线的零值不是同一种基础发声。某个元音的预测基底本来很强时，负增量可能正在提供柔和处理；不能把它换成统一的“温和正值”。按当前元音的预测、已有最终输入与实际音频响应逐段决定降低、保留或重设，检查其它强字是否因改动反而增加高频。谱能量变化是响应证据，仍不等于舒适度已接受。

**元音承载正确，但实际主体突然变小**：确认发声层已合适后，独立选择输出包络补偿。按需要的进入、主体、恢复与退出选有限节点或平台；节点由当前音乐判断设计，不复制参考控制数组或原唱的逐帧能量。词内或连唱的补偿连续经过连接位置，不在每个字界重置零；与正常尾音、尾辅音和AP/SP的退出分开。

**弱发声与尖紧同时存在**：降低过度张力可能使能量再下降，按调整后的真实声学输出设计包络。可以做发声、包络及组合对照，不能把组合改善解释成某个因素因果已证实。增益不会修复错误元音或音色；气声表面不等于削弱有声核心。

**其它部分**：明确保留既有自主函数与参数；不要把同一个波形、比例、张力或增益应用到每个字。整曲覆盖包括不修改的反例，不能用局部修复代表全曲检查。

## 原生与音频验证

从当前软件声明读取DYN单位、范围、默认值与实际处理阶段。写入工程、原生加载的数组、波形上的增益是三层检查。若原生五tick取样或采样时钟与直接插值不同，使用原生处理或记录差异；不能交付一条编辑器曲线，却用另一条手工增益制造音频。

同条件重新合成修改发声输入的完整上下文；包络只是后处理时，明确哪些预测条件及波形可复用，并校验依赖。核查前导尾帧和所有AP/SP，避免给换气或尾辅音一并抬升。最后重新测全曲实际元音包络和峰值，检查选定落差确实缩小、自然收尾仍存在。

对照共用伴奏、时钟与整体增益，直接截完整混音，不分别归一化。必要时声明单次全曲余量；不以逐字响度一致为目标。作者没有写DYN时如实记录；当前库的补偿是本次工程选择，不能说成作者历史手法。参数和能量改善仅证明响应；没有听觉检查则不宣称尖锐感、自然度或舒适度已解决。
