# 一句完成，再画下一句

用于整曲制作、重画和局部修订。Agent以一个完整音乐乐句为当前工作单元，像人工画线一样，完成观察、构思、落线和回看后再进入下一句。整曲任务增加循环次数，不降低每句的设计与审阅粒度。

## 先确定句子与上下文

先通览歌词、段落、原曲及谱面，建立有序乐句清单；可批量生成源观测、底谱和原生身份，数值画线尚不开始。按呼吸、语义与旋律连续性划音乐句，不把模型RenderPhrase、单字、固定秒块或重复歌词直接当音乐句。

当前句带前后相邻上下文观察。连音、同元音延续、转音准备或模型依赖跨界时，记录实际依赖范围；必要时把不可分的相邻句合为当前单元，说明原因。局部修订只写授权区域，邻句只读；不能为拆句新增休止、改音素时钟或丢失承载。

## 当前句的工作循环

1. **看源并构思。** 打开当前整句的连续原曲观察，核对歌词、音素与旋律身份。按每字和延续音乐阶段分别说明入口/到达、主体、下一字准备/退出；标明源事实、解释、艺术选择和unknown。决定哪些地方稳定、哪些需要回探、推进或展开。不要仅给一句情绪说明。
2. **先定能检查的后果。** 按当前知识接入和执行契约，在本句数值计划尚不存在时冻结意图。每个独立音乐主张都有自己的gesture/检查与局部支撑；跨字共享需说明实际连续关系。主体的运动另检主体，入口另检入口，不能用一个大入口让整句其余字通过。有限回收检查有序转向/恢复，持续展开检查实际存在区、幅度/峰谷或周期；有理由的稳定用hold/may_match。不统一最低音分，不要求每字颤音。
3. **只画当前句。** 先选音乐中心与完整走势，再画有限运动、必要周期和授权发声过程；节点、斜率与时序都依据这句。原生before-PITD只供编码。未完成后句的源判断与闭环前，不为后句写数值函数、入口剂量表或统一“到达后保持”的目标。脚本可执行当前显式函数，不能先替全曲发配动作。
4. **原生落线并回看。** 编译当前句，打开其全部字/延续段的完整实际视图及邻接，再回看整句。分别验证每项事前主张，检查主体是否被平台、连接、过早退出替代。核对实际线与浅/快备选在该主张上是否有区别；逐字记录具体观察，不把同一整句评语加一个范围值重复到所有字。发现缺失，先在本句修订并保留旧版；不把有明确缺失的句子列为完成后继续批量铺开。
5. **检查成声与交接。** 按任务范围渲染本句或含依赖上下文的片段，重建音高/音素/声线改变所影响的预测和实际输入，核对包络及边界。早期代表句及时提供试听；不要求用户每句确认才继续。没有听音能力就记未听，用户未反馈就记待听；技术或图审通过不能宣布好听。

完成上述当前句复核后，保存本句快照与状态，再开始下一句的数值设计。原曲本来不确定但已作明确艺术选择、可检查后果已实现的，可作为候选继续；已发现的漏画、错字界或动作检查失败须保留为待修，不能标ready。用户明确要求先交失败/缺口候选时遵从，并单列未完成句。

## 保留可继续的进度

每个制作run维护一份有序逐句进度记录（例如`phrase-progress.json`）。记录音乐phrase_id、实际note/unit IDs、授权写入区和邻接依赖，以及当前版本的源观察、意图锁、函数/ledger、原生导出、实际图审/critique、渲染/输入检查和未解决项的路径/SHA。

每句区分`pending`、`working`、`ready_for_next`、`needs_revision`；`listening`另列pending/relative_preference/accepted及准确范围。一个工作单元ready后才新建下一单元的数值计划；不在整曲已出线后倒填逐句完成顺序。中断后从正在处理的句子及其具体缺项继续，不把所有后句先填成默认平台。

这是Agent的执行记录。现有工具只验证各自支持的字段和绑定，不自动证明真实工作顺序或音乐理解；不要把本进度文件当现有CLI已经实现的新门禁。

## 使用现有编译器与组装

当前`compile-functions`外层只接受`scope: whole_song`并要求覆盖输入工程的全部原生短句，尚无局部范围参数。它的“全部”是当前输入工程，不能因此先批量设计整首歌曲。为当前音乐句建立保持绝对时钟的工作副本，覆盖它所需的原生依赖并走既有inventory/intent/ledger/图审契约；源上下文与可写区域分开登记。不要伪造`scope: phrase`或假定自定义进度字段已由编译器验证。

提取副本可能改变声母、分句或模型上下文。提取前后先核对当前句实际时钟/身份；无法等价时保留必要上下文，冻结其边界而不随意重画。回写完整工程后再次导出，证明授权区与已审阅目标一致，授权区外所有不相关音符/控制/音高精确保持；受邻接影响的部分回到相关句复核。局部工作副本的通过不能直接冒充完整工程/成声等价。

整曲最终组装只消费已经逐句复核的目标，不重新生成入口参数或为未完成句补平台。可批量做确定性编码、最终渲染与技术核对；先后边界、跨句声线、强弱和整曲听感还须复查。若发现问题回到具体句及依赖范围修订，不自动扩大成整曲参数扫描。整曲总览不能替代各句工作循环，逐句都画完也不自动等于听觉接受。

## 现有检查的限制

当前音乐检查器对一个gesture的`must_differ`只要求其中至少一项判据能否决浅对照。因而不能把多个独立字/主体主张塞进一个gesture，用某一个入口的成功代表全部有区分力。将独立主张拆开检查，并逐项核对其实际/备选后果；当前代码没有自动发现所有语义漏项的能力。

`landmarks`可检查到达，但几个入口点不能证明持续主体已展开；helper的宽幅编码包络、首中尾函数跟随、节点数量和图像访问覆盖也不能证明它。保留每字/阶段的真实取舍与未满足主张，禁止用增加节点或统一加大波动应付检查。局部相对偏好不冻结整句所有路线，更不替代后句重新判断。
