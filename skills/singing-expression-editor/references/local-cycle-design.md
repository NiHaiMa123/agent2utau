# 局部周期、频率与振幅

适用：音高线像平台、周期缺失、幅度或速度不合适。先遵守用户的参考授权范围；源F0周期检测是观察，不能成为Agent选择周期的硬门槛。检测失败保留unknown，不把来源不足改写成无需周期。

## 测量量与单位

读取最终绝对线及实际元音时钟，逐个标出峰—谷—下一峰，记录局部间距、`Hz=1/峰间秒数`、峰谷偏差、中心走势和进入／退出。周期速度用Hz与物理秒，音高振幅用cents；两者不是绝对F0或人声音量。

半幅、峰峰值、各峰／谷相对主音的偏差是不同量。需明确所学量，分别保存实际峰、谷和中心，不把半幅直接当每个峰值，也不以相邻峰平均制造未观察谷。跨主音转向、单次弯折和假峰先排除；检测结果只是候选。原生意图线不证明作者历史音频或绘制过程。

## 按支撑和音乐作用选择

持续周期之外的有限运动及整句分布先按[整句尺度与字腹运动](phrase-scale-contour-study.md)审阅。不能以周期候选数决定其它字为平台，也不能只在局部纵轴放大后判断幅度已足够。短支撑允许少量完整波及起尾部分波，前提是音乐目的和实际元音支持，而非最低完整周期数门槛。

| 条件 | 处理 |
| --- | --- |
| 同元音同主音跨多个音符延续 | 合并实际可用支撑并保持相位连续，不按每音重起 |
| 持续字需要展开 | 分段选择周期存在区域、逐周期深度与速度；不只允许固定末尾窗口 |
| 持续字需要留住或克制 | 可选平稳、浅小变化或晚进入；长音不自动深颤 |
| 较短元音有运动意图 | 核对入口／主体可用段，可选局部倾斜、下探或回收；不以统一最低时长排除所有表达，也不硬塞固定周期数 |
| 中后段需要回收 | 选择收浅、停止或转慢走势；参考序列结束后重新决定余段，不自动循环末周期 |
| 周期要截止 | 继续物理相位并以独立深度包络渐隐，或明确转入释放；不拖长剩余半波填满支撑 |
| 最终坡度抵消局部峰谷 | 协调入口、连接、中心走势与周期支撑，不默认放大振幅或放宽门槛 |

频率按真实秒数安排，数量由速度和支撑共同产生；不能为了复制参考数量整体压缩或拉伸周期。深浅与速度可以改变，也允许无周期。整曲统计与段落标签不能直接成为全字默认或裁剪边界；经过条件分组、原例及反例核查的范围可用作[条件配方](conditional-drawing-recipes.md)中的首轮数值候选。跨曲选择仍说明当前音乐依据和外推，不因尚无普遍听感验证而只给检查口号、不提出具体画法。

## 执行与最终线核对

浅小变化、周期的不对称、中心走势及发声释放的关系见[细部画线与声学解释](microexpression-and-acoustics.md)。同时放大浅运动和明确周期，避免只学最大的峰谷；量化折点不自动作为生理或可听变化的证据。

`periodic_landmarks`执行稀疏有序峰谷、原生锚点及cents偏差，可变时距、偏置、深度。`dynamic_periodic`适用简单变深变速波动，必须用 `phase(t)=phase0+2π∫rate(s)ds`，不能用f(t)×t。带独立渐隐的接口见[上下文执行](context-execution.md)。函数只执行已选计划，不判断音乐目的。

检查最终叠加线的有序峰谷、局部间距、逐周期深浅、第一／最后部分波、浅深转折和body／entry／release衔接。分开报告计划周期、实际存活周期与未解决项；完整周期算术通过仍可能漏掉错误存在区域。平均频率、整曲数量、局部中位数和跟随自己目标均不验收自然度。

试听固定谱面／音素时钟、声线、其它控制、随机条件和全曲混音；重算新pitch的variance／acoustic依赖。原样截取上下文，不逐字或逐片段归一化。没有听音评价器时只报告执行与声学核查，用户反馈绑定确切音频。继续动作选择时读[新歌动作选择](new-song-action-selection.md)。
## 长音中的阶段选择

一段有深浅变化的周期函数仍可能在整字中重复同一运动。按[多通道发声与长音阶段](joint-phonation-and-sustain.md)重新判断是否需浅维持、局部回收、暂停后再展开；各阶段独立安排中心、速度、非对称和部分末波。张力下降与音高周期展开可以同时存在，不能把所有通道锁到同一包络，也不能以非 pitch 控制掩盖未设计的字腹。
