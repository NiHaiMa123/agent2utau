# 局部试点边界

局部任务先声明完整音乐/音素上下文、用户反馈位置及实际输入哈希。Agent选择有限范围中的动作、参数、目的与备选；保留一个合理未处理对照。不用旧body_bend/delayed_vibrato包装器或历史规则模型选择动作。

使用当前函数helper或schema3接口采样，再按docs/workflow.md接入原生工程。通用compile-functions要求覆盖输入工程全部原生乐句；局部工程须明确来自原全曲的哪些上下文，不能切断同一字的延续、下一字辅音或AP/SP接口。局部通过不能称为全曲通过。

发声试验一次改变声明因素，保持非选输入和增益；音高/声线/分句改变后重算两阶段依赖。对照记录实际speaker、模型、种子、原始预测、人工增量、最终特征和波形拼接。未选择的候选只用于诊断，不自动写入正式工程。

数值跟随/谱形/RMS变化不等于听觉改善。没有听觉工具时交付同增益对照并标明待用户试听，不宣布自然度已解决。旧失败和旧冻结状态不能因Skill文字更新变成有效。
