## Key facts (verified @9699944)

- No headless render CLI in OpenUtau; `a2u-bridge` reuses OpenUtau.Core in a
  self-contained exe inside the install dir. deps.json is generated by cloning
  the OpenUtau entry in `OpenUtau.deps.json` (see `openutau/bridge.py`).
- Bridge needs `Encoding.RegisterProvider(CodePagesEncodingProvider)` or singer
  discovery silently returns 0 (shift_jis GetEncoding throws).
- `PostOnUIThread` must queue to a real single-thread pump, NOT inline — inline
  re-enters ExecuteCmd on the wrong thread -> infinite recursion.
- clr note values index into alphabetically-sorted subbank colors; clNN curves
  index into character.yaml subbank order (1-based). Old->new map:
  {0:0, 1:2, 2:3, 3:4, 4:1}.
- Part curve xs are part-relative ticks; note positions are part-relative;
  part.position is project-absolute.
- Render cache lives in install-dir `Cache\` keyed by phrase hash — repeat
  renders are instant (cache hit); a different phrase is a cold render.
