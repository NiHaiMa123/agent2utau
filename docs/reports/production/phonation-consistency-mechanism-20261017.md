# 虚实程度与一致性机制：首版实现及当前覆盖缺口

用户要求构建虚实程度判断机制，并反馈当前一致性仍差一点。本轮新增只读评价代码、合成/契约验证、当前自己前三句前后版声学观察及Skill接入；歌曲/音频保持，没有自动修歌、作者载荷或新歌声合成。单Agent、CI未运行。

## 已实现

入口为 `python -m agent2utau.evaluation.phonation --manifest <JSON> --out <新目录>`，实现位于 `src/agent2utau/evaluation/phonation.py`，完整定义、输入schema和局限见[使用指南](../../guides/phonation-consistency-evaluation.md)。

机制分三层：原生实际控制只用于定位输入变化；输出PCM提供逐元音可靠窗口的周期性/高频平坦度，以及单列的谱倾斜/RMS；用户连续上下文反馈提供有范围的听觉校准。没有把VOIC/BREC或响度当虚实真值。代码不读制作expectations、不搜索旧缓存或作者目标、不自动反算参数。

同一phone、相近实测音区的其它元音才作主要参考，剔除同unit自我参照；输出相对虚实代理、参考距离和覆盖。代理以两个声学分量的固定中位数/MAD尺度构成，不是0–100听觉分，也无“更高更好”或通过阈值。一个参考元音只产生很有限的临时对照。谱倾斜/音量单列为声色和强弱混杂，不并入虚实分数。

每个元音的入口/主体/退出保存原观测帧与拒绝原因。两份实测F0不一致、跨辅音、短时/低电平/削波风险及高频能量不足时保持unknown；无同类参考也保持unknown，不能拿少数可比字替整句。跨版同一个字的实际响应单列，和更接近邻句、听觉通过分开。

## 冻结和验证边界

先按表1 S1/S2/S3及PER:S1协议和正反反馈生成SHA绑定知识上下文，再在 `frozen-method.json` 固定指标、窗/参考条件、权重/尺度及覆盖标准，随后实现和测当前声音。当前标签未用于拟合权重或通过线。首次运行保存在evaluation目录；之后按纯正弦合成反例补入高频数值底噪unknown门禁，单列quality-clarification，最终结果另存evaluation-final，没有覆盖初版或为当前听感调分。

本实现是明确的周期延迟相关/频谱代理，未调用Praat或Parselmouth，不冒称精确Praat HNR/CPP、真实噪声百分比、声门闭合或生理气流。官方说明支持元音/频谱条件与动态窗限制，未验证本算法/声库的听感映射，来源见指南。表1/表2既有measurement_validated不升级。

49项本机检查通过，覆盖周期+噪声方向、音量缩放不改变形状代理、不同F0、无高频不能冒充噪声、静音/削波/F0分歧、辅音/短元音排除、音区/元音不匹配和自我参照、低覆盖不冒充全句、音频/F0 SHA与时间域/混音错误、输入只读及同manifest结果确定性。合成测试不等于真实歌声准确率或独立盲听考核。

## 当前前三句的实际结果

只读取本次当前自身歌曲最近BREC修订的连续before/current两版，时钟16.25–31.95秒，首两句PCM相同；来源和绝对时钟逐项绑定，重新提取4组FCPE/RMVPE观测。原生phone时钟来自已核对的当前工程，不用函数计划期待作真值。

- 共23个元音（窗内u/ang分列），22个有足够主体观测，合计784个有效窗；窗的短u不满足主体最少窗数而保持unknown。计数是音素元音，不冒称22个字都重新制作。
- 第三句8/8元音有可用输出观测，但只有“了”的e和“泣”的i能在前两句找到同phone/近音区参考，比较覆盖2/8=25%。其余下ia、两次雨v、陪ei、我uo、哭u缺少同条件参考；它们不是异常或通过，而是尚不能校准相对程度。
- 第三句当前这两个可比元音的周期性/较不平坦方向代理相对参考为正。上一轮减BREC使它们周期性代理上升，同时参考距离代理分别从约1.84→2.41及1.15→2.08。这里只能说这两个字的声学变化没有更接近所选参考，不能说整句听感恶化、已经过实或BREC全无效。
- 用户认为相对一致的第一二句，某些条件对照的声学距离本身也不小。因此当前代理尚未学会“何种差异仍是同一演唱状态”，不能设统一阈值反驳听感。当前用户“仍差一点”是反馈记录，不冒称由本工具独立检测/正确分类出来。
- 三句都标insufficient_matched_coverage；整句虚实程度/听觉一致性仍unvalidated。当前只能提供逐字变化、局部条件差距和缺口，不能给可靠的全句虚实等级。后续随逐首制作补足同音素/音区的听觉参考并设留出验证，再校准刻度；不因缺口自动展开新批生成或继续加参数。

当前机制已可运行并阻止把少量指标/有限参考冒充整句判断；完整听觉区分能力尚未完成。这两个状态分别保留。
