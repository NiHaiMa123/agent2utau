# 非C直接反馈：F更实，D暗，F好很多

按顺序保存同一D→F试听的两条用户消息：“f更实”；“D暗。F好很多”。分别记录F相对D更实、D为比较中更暗的一端，以及整体明显偏好F；原话不转成数值提升幅度、F绝对合格/整句采用、无尖挤、无气声或压低声音唱完全消失。D暗来自对“哪段更暗”的直接答复，不改写成新的压低感排序；F更清亮只是对D更暗的相对解释，不另造绝对清亮等级。

两条消息属于一组连续试听事件、不是两个独立样本；关联紧邻先D后F整句交付，用户未另供播放文件SHA。原PCM、先前pending模板和无预设排序的protocol保持。新部分标签firmness=side B(F)、timbre=different；偏好与暗度方向另存，不把“好很多”填成自然度或响度。

## 与反馈前已有声学观测核对

8/8共同元音主体，先取每元音配对差再等权中位汇总，F减D：周期性代理约+2.765dB、高频平坦度−0.951dB，方向与F更实相符。该指标在交付前已经生成并封存，原测量/算法未改；这是补充标签后的局部方向复核，没有事先宣称D/F听觉排序或冒称盲测预测命中。

同时F减D的输出谱倾斜约−0.590dB/oct，即F的该指标更负，用户却指出D暗。它否定了在这组上用“该谱倾斜更负就听起来更暗”的直接排序；不推断所有明暗指标无效，也不为追当前标签翻转符号、拟合门限或新造特征。逐元音方向并非听觉逐字标签，完整数值绑定原acoustic-diagnostics.json。

当前增加一条不含C的直接虚实边，且较实的一端不是更暗的一端，不能再把“暗/压低”当作实感定义。连同旧四组，五组汇总虚实方向吻合；仍仅一个明确标注虚实排序的完整句上下文，且样本共享、发声两项不同。不是五个独立样本、100%准确率、单通道规律或跨句能力通过。新F偏好不覆盖旧C/F相对虚实关系，也不推断F是所有版本最佳。
