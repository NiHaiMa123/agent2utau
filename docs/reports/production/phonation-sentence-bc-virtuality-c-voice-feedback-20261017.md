# B/C反馈：B更虚，C有压低声音唱的感觉

用户原话：“b更虚，但是c感觉像是压低声音唱的”。关联紧邻B→C整句RMS匹配交付，用户未另报文件SHA。仅记录本句本条件B相对C更虚，以及C的“像压低声音唱”这一额外发声听感；不把它改写成实际降调、生理压嗓、TENC升高、已证明病因、偏好C或自然实声接受。A/C与B/C两条关系不能补出A/B排序。

C更不虚和C的该发声特征分开：宽组合端点足以支持局部区分，不足以充作合格的实声目标。此前C/B输入音高与张力相同，仅限制实际写入路径，不反驳用户听感。下一有限对照固定C的VOIC和全部其它条件，仅恢复BREC为零人工增量D；用完整句检验减气声处理是否参与该听感，结果待听，不同时试改声线/音高/张力或歌曲。
