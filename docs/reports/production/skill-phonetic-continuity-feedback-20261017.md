# 韵母发音接受与跨句虚实未达标：Skill回填

用户反馈“还是不够。还有之前的第一句窗字发音修好了，你看下skill有需要修改的吗”。本轮分别追加[窗字发音局部接受](../../../songs/yuai/reports/legacy/chuang-uang-clarity-accepted-20261017.md)和[第三句VOIC修订未达标](../../../songs/yuai/reports/legacy/third-phrase-continuity-revision-insufficient-20261017.md)，显式登记公开知识来源，再生成本轮SHA绑定上下文及逐ID决策。旧记录/收据/上下文不刷新。

## 反馈范围

窗字接受仅指当前字的发音修复，原先ch定位已撤回，实际为复合韵母uang。显式ch/u/ang和内部时间安排是当前条件的局部可用证据，不推广成所有uang必拆、介音固定55ms或统一比例；全句实感与全曲状态另列。

第三句“还是不够”表示已交VOIC单通道修订仍未达到前述虚实连续性目标，不补造“完全没变化”或其它细分标签，也不否定整个VOIC通道。当前工作工程仍保留该未达标版本供追溯，没有回滚/追加剂量或生成新音频。用户未指定实际听音文件SHA，公开记录只关联交付候选和当前工程，不宣称已确认精确播放文件。

## Skill改动

使用singing-expression-editor及skill-creator审阅后，仅改四份已有资源，不新增模板/脚本/固定剂量：

1. `SKILL.md`：增加发音不清/复合韵母含混的直接路由，避免只有节奏和支撑入口。
2. `references/vowel-support-and-language.md`：补复合韵母内部时序。先定位声母/介音/主元音/韵尾；模型token合法和总时长正确不保证内部过渡清楚。只在当前模型支持时尝试同一汉字/音符内的显式音素提示，先导出实际phones再决定offset；重查索引、单位和邻字连带移动，恢复非预期变化。新音素需重建预测，发音接受不继承为虚实接受。
3. `references/phrase-by-phrase-workflow.md`：数值设计前说明当前句承接邻句的声线/虚实意图及有依据的变化；逐句工作不等于逐句重选发声。将当前预测检查明确放在最终pitch/phones/speaker条件确定后、写人工发声剂量前，避免只在成声后补看。涉及声线/虚实改变或跨句反馈时，交付同增益相邻句连续对照；不新增逐句等用户许可。
4. `references/phonation-continuity.md`：明确同配比不保证连续、不同特征也可能听感一致。用户否定有限VOIC方案后暂停同方向自动加码，临时模型中位数目标、补偿比例或剩余声明范围均不是加量充分依据；重新区分未解决的听觉维度再选有限对照。

这些是一次局部接受及一次未达标反馈支持的方法约束，没有新增听觉真值、跨曲效果或通用剂量结论。既有方法已包含跨句要求，本轮补的是决策落点和停止条件；仍需Agent实际执行，没有新增自动顺序门禁或可靠的听感分类器。
