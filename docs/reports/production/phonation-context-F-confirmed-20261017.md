# F接入连续诊断：更好，虚实基本一致

用户原话：“后面的更好，基本一致”。紧邻交付为先现版前三句、后F接入诊断；问题明确询问第三句与前两句的虚实一致性。因此记录后面的F接入组合整体更好，在这一连续上下文中第三句与前两句的虚实基本一致。实际播放文件未由用户另供SHA，按交付次序和问答上下文绑定，不补造独立播放凭证。

这是新的跨句听觉正例，不是从先前F比D更实的局部关系推导出来。只确认“基本一致”，不改写为完全相同、逐元音同一虚实程度、全句所有方面通过或整首接受；用户没有新增暗/清亮、响度、气声、尖挤或独立发声力度标签。

## 已确认的组合

前两句及第三句前空白沿用当前原PCM；第三句26.35–31.748707秒使用已有F研究音频，音高/音素时间已按原生身份核对一致，仅施加一次固定整句增益约2.294490（+7.213723dB）匹配当前第三句整段RMS。没有逐字归一化、EQ、压缩或新生成。该增益是在原F试听衰减后的PCM上施加，不是推导出的通用制作增益。

新听觉确认覆盖的是F发声、既有逐字强弱、固定增益和当前前两句组成的这份连续音频。不能据此将改善唯一归因于VOIC、BREC或增益，不能说单独调响就解决虚实；单一因素与跨条件推广仍unknown。原USTX未写入F，工程现有第三句不因本条反馈获得确认。

## 作为机制参考的用途

追加一个来源明确的真实连续语境正例，保留“基本一致”容差语义，可用于后续评价器检查：面对已确认的连续组合，是否错误用声色、音量或少量参考距离宣布不一致。没有把此标签作为拟合分界后再考核自己的独立留出，也没有给每个元音补实感等级。

原工程的第三句跨前两句条件参考仍2/8，同句D/F可比8/8；新正例不改变这些测量覆盖。诊断音频没有独立重提F0，原F的F0也不能冒名绑定到新PCM；后续若测此正例须绑定新音频并重新观测，明暗代理与通用听觉刻度仍未校准。原pending模板、测量结果、反馈与receipt保持。
