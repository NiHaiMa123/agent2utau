# 既有整句试听标签对声学代理的开发考核

四组已确认的相对虚实比较，周期性上升/高频平坦度下降的整句方向均吻合。但这不是已完成听觉评价机制：四组共享同句的C，且C同时带压低声音唱感觉及更负的输出谱倾斜，无法识别究竟区分了虚实、声色还是二者共同变化。没有独立虚实标签的G/H/I，不能据其偏好/暗清亮反馈算虚实命中率、误判率或证明声色分离。

## 方法与复现

按用户“下一步”先冻结protocol与知识接入，再仅重读已有9份RMS匹配整句PCM和各自已有FCPE/RMVPE，不进行原生、F0或歌声模型推理。保持原算法v2、参数和旧结果。当前源码SHA与原algorithm-v2-freeze一致；9版全部测量帧/掩码及四项特征与旧观测精确复现，最大差0。旧run/音频/报告/收据不改。

新增只读API `evaluation.phonation_audit.compare_pair`：同phone、同音素支撑、同句身份，只配对双方均可靠的主体中心（微秒键、跨版音高差≤3半音），每元音至少5点；先取每元音右减左的配对差中位数，再取元音间中位数，避免不同掩码或长字帧数支配结果。该交集仍不是完全相同的样本窗长度，F0会改变窗长；不冒称完全隔离音高或声色。方向诊断用1e−9仅排数值零，不作可辨门限。没有拟合权重、合并分、自动修歌或将方向主张写入测量器。

## 已确认与未确认

四组A/C、B/C、D/C、F/C均有8/8共同元音，汇总两轴方向4/4吻合。逐元音周期性方向32/32一致、平坦度30/32一致；这些是数值分布，不是32个独立人工标签或用户逐字认可。全部较实右端均为C，只有一个有明确虚实排序的句子上下文，不能报100%听觉准确率、跨句验证或理想实声接受。相同测试端点还伴随不同的局部RMS；整句RMS匹配并未抹掉字内强弱。

D/E原反馈“差不多”仍有效：周期性配对差约+3.787dB，平坦度−0.636dB，却没有人工可辨/虚实排序标签。不能用F/C的约+3.195dB周期性差直接设统一可辨线，更不能将D/E标成听觉不同。H/I整体近似、各自好于G也不是逐轴相等或虚实排序。G/H/I每对5/6元音共同可测，窗短u unknown；这不补足原第三句跨句参考2/8缺口。

已有数字开发信号中，保持音高/种子/组分信噪比/增益、只换滤波的稳态比较，周期性变化最大约1.984dB、高频平坦度约4.168dB、谱倾斜约4.970dB/oct。保留所有组合明细，不只选最大值。这证明代理受谱形影响，不能从高频平坦度单独读出虚实；数字组分SNR相同也不等于真人听感相同，不能把它们当作已标注的“声色变化但虚实不变”人声样本。只读取旧开发集，未重新使用留出选择门限。

## 能力结论与下一步

当前：测量复现通过；已有标签的局部方向复核通过；虚实/声色的独立判别仍未证实；可辨程度、跨句一致性与新歌迁移未校准。当前工具只提供分轴观测和标签来源，不能给整句虚实等级或反算VOIC/BREC。故本次没有把评价机制标成完善。

下一步优先检索现有允许的公开反馈，寻找不共享C且能独立约束虚实和声色的完整句对照；旧工程/作者数组仍不进入设计。若已有标签不能提供这样的比较，再用最少的已有PCM对照补专门维度，不重开单音矩阵或加密剂量。需要验证“虚实相近但声色不同”及“声色相近但虚实不同”两类关系，不能用声学指标先替它们命名后自证。新的评分规则须另行冻结，再用未用于定规则的连续语境验证。
