# C/F反馈与第一测试句小结

用户原话：“减轻，c更实”。紧接C→F及关于F的两个问题，记录为F相对C的“压低声音唱”感觉减轻、C相对F更实。关联按紧邻主交付和字母指代，用户未另报音频SHA；不改写成F完全正常、C/F偏好、实际降调/生理压嗓或接受。

| 已听比较 | 支持的有限结论 | 仍未知 |
|---|---|---|
| A/C：“a更虚” | A比C虚 | 其它发声特征、偏好/绝对合适 |
| B/C：“b更虚，但是c感觉像是压低声音唱的” | B比C虚，C有该额外听感 | B与A/D/E/F关系、C是否合格实声 |
| C/D：“减轻，但是更虚” | 撤回负BREC的D比C虚、该听感减轻 | 唯一病因、全部其它语境 |
| D/E：“差不多” | 整体近似，未获清晰中间档改善支持 | 分别两维是否等价 |
| C/F：“减轻，c更实” | 撤回VOIC增量的F减轻该听感，C比F实 | 唯一病因、D/F比较/交互、最优配方 |

同句在分别撤回两项控制时，都报告实感与该发声听感共同变化；支持这两个局部干预都参与当前条件的权衡，不能称为唯一成因、两项作用相加/无交互或自然实声刻度。输入隔离使用原生默认随机状态，整句RMS匹配非严格等感知响度，边界保留。所有旧pending/报告/数据保持当时版本。

此句停止新增参数点，不再生造G作为其折中。下一测试换“窗外的天气”，固定该句当前谱面/音高/音素/声线，按同一有限元音内处理规则重建三个条件，先冻结方向预期再生成，分别检查有声支撑和减气声的相对关系。它是已见曲目的另一句/新条件，不是新歌或独立盲听留出，不沿用第一句历史接受标签。
