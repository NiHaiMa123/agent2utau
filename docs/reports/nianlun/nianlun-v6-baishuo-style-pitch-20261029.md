## 二、白烁画法的实测结构（499 音符 / 15763 点）

从 `research/baishuo/projects/雨爱-有参by白烁.ustx` 只读归纳（**学做法，不复制数值**）：

| 特征 | 实测值 |
|---|---|
| 音高线载体 | `note.pitch` 全部保持**直线**（每音符 2 点，y=0）；**所有细节画在 PITD** |
| PITD 密度 | 11082 点 / 151685 ticks，step 中位 **10 ticks ≈ 15.6ms** |
| PITD 幅度 | mean\|y\| **69.2c**，std **124.7c**，范围用满 -1200..1200 |
| 零值占比 | 仅 1.8%（\|\<50c\| 占 **65.4%**） |
| 字头 (u<0.15) | 中位 -5c，**p10 -153c**，std 110c |
| 字腹 (0.35-0.65) | 中位 -3c，**p10 -175c**，std 160c |
| 字尾 (u>0.85) | 中位 -8.5c，**p10 -220c**，std 166c |
| 字腹幅度 vs 长度 | 短字 std **13.5c** / 中字 **20.9c** / 长字 **60.6c** |
| 曲线平滑度 | 二阶差分中位 **12c**（平滑手绘，不是噪声） |

**核心规律**：字头滑入、字腹随长度展开、字尾滑出，用密集 PITD 逐点画出。

## 三、v6 的做法

按上述结构重画（**参数由音乐条件决定，不是抄白烁的数值**）：

- 载体：PITD，**15 tick (15.6ms) 步长**，51 parts 共 **12437 点**（与白烁同量级）
- `note.pitch` 保持直线（与白烁一致）
- 字头滑入：句首 -190c，上行大跳 -150c，同音重咬 -95c
- 字腹：短字 45c / 中字 85c / 长字 140c 基准幅度，再按源"有无运动/是否周期"缩放
- 字尾滑出：句尾 -170c，下接大跳 -140c
- 平滑插值（quintic），保证二阶差分小

| 指标 | 白烁 | v6 | v5(太弱) |
|---|---|---|---|
| PITD 点数 | 15763 | **12437** | 12437 |

| \|\<50c\| 占比 | 65.4% | 48.8% | 92.0% |

> v6 的幅度已接近白烁（58.9 vs 69.2），但 std 仍偏低（45 vs 125）——白烁有更多极端值（满量程偏移），我还没有放到那个程度。

## 六、诚实的边界

1. **听感未验证**：我没有音频感知工具。v6 是否"更像"必须由人耳判断。
2. **std 仍低于白烁**（45 vs 125）：极端偏移（满量程）还没有放到同等程度。
3. **音色层未启用**：工程 `clr` options 仍是 `['']`，5 种音色一个都没用；
   白烁的工程用了 cl01-cl05 混合。这是**下一步最可能见效的改动**。
4. **辅音/咬字**：实测辅音时长正常（中位 140ms，无过短），
   但 ASR 反向识别 bigram-recall 73.8%（原唱 79.5%），咬字清晰度仍有差距。
5. 复用了用户授权的观测（分离/GAME/双F0/ASR）。
