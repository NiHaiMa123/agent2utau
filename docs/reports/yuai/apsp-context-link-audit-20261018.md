## 3. 为什么填空白可能影响唱声

AP为显式呼吸token，SP为显式停顿token；它们不仅对应空隙里的声响，还进入音素/语言编码和模型上下文。在这里把标签放进原有间隙，可以改变原生段如何连接、模型看到的前后音素与停顿长度，以及重新预测的音素时序、气声/有声/张力和声学条件。原生RenderPhrase不等同于一口气，AP/SP在同一预测段中并不意味着所有字一直连唱。

同时，**没有显式标签不等于模型完全没有SP**：当前DiffSinger工具给每段加头尾SP，单段内部若存在phone空隙也可插入隐式SP。关键区别是隐式SP出现在什么计算上下文里：已分开的两段padding不能让模型跨段看到另一侧音素。当前源码的[PaddedSegments](https://github.com/openutau/OpenUtau/blob/master/OpenUtau.Core/DiffSinger/DiffSingerUtils.cs)可作机制旁证，本机实际分段以上述原生导出为准。

上轮已用当前语言ONNX证明相同中心16个phone/token/时长/language在不同周围上下文中的编码变化；本轮进一步把“作者显式AP/SP”与“原生分组改变”这一结构链条接上。这仍不足以推出所有听感差异都由AP/SP造成，或AP/SP填得越满越好。

## 4. 下一步检验与当前保持

应优先在我们自己的时间轴上选择第三句必要的静顿/呼吸连接，做有限的原生上下文成声对照，固定其余声线与人工发声，按新phone与before-PITD重新核查音高和边界；保持可比较随机条件或重复基线。AP/SP数量、方块覆盖率、段数减少都不是听感通过，尤其不能把整曲所有空白铺AP来追求参考外观。真实吸气只放在合适位置，SP和保留空白也可有理由使用。
