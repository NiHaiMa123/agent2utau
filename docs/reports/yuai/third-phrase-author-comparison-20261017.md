# 第三句仍不一致：白烁工程只读对比

用户最新反馈“还是不行，这次你看下白烁的进行对比”。本次按授权读取白烁雨爱原件，对照当前同一USTX前四句，重点第三句“下雨了，雨陪我哭泣”。第三句目标仍未达成；第四句“没问题”保留。没有修改歌曲、音频、Skill或原作者文件，没有生成换库作者声音；单Agent，CI未运行。

**主要发现：当前第三句换了整套发声实现，和声部结构、音高路线及长字时长也与作者不同。版本写回只解决交付遗漏；不能由“输入等于F”推断演唱状态已经与邻句一致。当前最有针对性的检查线索是有声核心与气声表面的组合及同元音跨句关系，不是继续减BREC或统一加深音高波动。**

## 1. 主唱发声控制：作者相对稳定，我们分段换配方

对齐31个唱字的歌词顺序与记谱中心，主音全部相同。作者使用旧yousaV1.56，当前使用YousaV1.65b；旧库不在本机，历史作者音频未提供，以下作者数值只是书面控制，不能当相同模型的输入或生理真值。

|当前句|我们书面控制（诊断窗范围）|白烁主唱书面控制|
|---|---|---|
|第一句|VOIC134–199，BREC0，cl05=35|VOIC114，BREC0，cl05=59|
|第二句|VOIC133，BREC0，cl05=0|同上|
|第三句|VOIC100零增量，BREC0至−80，cl05=35，DYN43|VOIC114，BREC0，cl05=59；末“泣”TENC7|
|第四句|VOIC100，第一“清”局部124；选定元音BREC0至−42，cl05=35|VOIC114，BREC0，cl05=59|

我们第一句和第二句声线/控制也不同，却已经得到相对一致反馈；第四句也获“没问题”。这是明确反例：**不同参数不等于听感不一致，统一所有值也不能自动解决。** 作者cl05对应Classic名称，但缺少旧库，不能将其直接解释成当前同样的Classic/Normal比例，更不能抄59或114。

本轮当前第三句F组合撤回了旧VOIC支撑，明显压低模型breathiness，再用DYN恢复整句电平。这个组合在旧对照里相对偏好更好，连续诊断也有“基本一致”反馈；本次原生写回仍被否决，不把旧正例抹除，也不将局部组合继续视作现版已校准。

## 2. 当前自身的同元音检查：减气声没有维持同样有声核心

“气”和“泣”均为当前声库zh/i、同MIDI68，使用各自实际元音内部25ms保护后的共同规则，读取当前真实模型输入：

|模型特征中位数|第一句“气”|第三句“泣”|
|---|---:|---:|
|预测voicing|−46.18|−45.21|
|人工VOIC增量中位数|+10.56|0|
|最终voicing|−36.05|−45.21|
|最终breathiness|−53.61|−65.68|

当前原始有声预测近似，但第一句有已接受组合的人工支撑，第三句F取消了它；最终voicing低约9.17特征单位。breathiness已经低约12.07单位。分别求中位数不能直接相加作为最终中位数；表中最终值直接来自实际输入。它们不是输出dB、HNR、气流或听觉程度。只有两个第三句元音能与前两句作同phone/近音区配对，仍不能给全句打分。

这指出上一轮处理的不足：主要用F的偏好/原生等价和整体RMS对应来落实，却没有把“有声核心、气声表面、明暗和增益”在当前连续语境重新分别判定。模型breathiness更低不支持声称已经听起来不虚，也没有理由因此继续加负BREC。已有C偏暗/压低感、D/F关系和有限VOIC未达标的阴性仍适用，不能直接改成无限增加VOIC。

## 3. 音高和时长：第三句有动作，动作位置却不同

当前第三句不是一根直线。作者也不是每个长字都深颤；末“泣”主体相对平稳，比我们的末段起伏更少。不能再以“曲线越大越实”作为修正方向。

- 第一“雨”承接前字的回探/再到达以及第二“雨→陪”的下行路线，作者写得更明显。第二“雨”后低位承接及后续“我→哭”的准备与当前不同；这些是跨字/到达过程，不能全部算作字腹颤音。
- “泣”的记谱时长：我们约0.914秒，作者约1.594秒，少约0.680秒；这是书面时长差，不依赖全局对齐偏移。会改变维持/释放的时间条件，但不单凭该差宣布虚实病因或直接延长当前音符。
- 作者“了”“陪”有−11/−23的书面音素offset，而当前无同样override。旧库/phonemizer真实phone时钟缺失，不能据此断言当前HFA错位或直接搬offset。作者拼音与当前中文提示最终均需通过各自声库映射，文字不同不直接等于发音错误。

研究图用各自第一唱字起点作显示零点，保留真实秒数，没有拉伸时长或拟合作者数组。作者线为书面note.pitch+PITD诊断重建，当前为真实原生最终线；不冒称两者都是历史声学F0。初版图画出了作者AP/SP/EP载频，修正版将其遮罩，旧图与勘误保留。第四句末“清”有内置vibrato，未重建而留缺口；第三句八字无此内置vibrato，书面诊断完整。

## 4. 和声：后半句另有一层，不能混成主唱实感

作者从第二个“雨”开始有高声部“雨陪我哭泣”：主唱MIDI64/61/63/64/68，对应和声68/64/66/68/71，原作者两个轨道均未mute。前两句无这层，第四句也无这层。它是可能改变厚度/空间与整体质感的具体结构因素；当前独唱没有这一层。

这不能解释作者前半句“下雨了”的主唱实感，也不能把用户要求的虚实一致性偷换成加和声。主唱须先单独校准，和声/双声部只在需要比较作品整体效果时另列；不通过加一轨遮住当前主唱差异。

## 5. 下一步应怎样改变

优先目标仍是当前主唱跨句同一演唱状态，保留已经认可的第一二句和第四句。先以当前自己“气／泣”等可比条件检查有声核心与气声表面的组合；固定现有pitch/phones、公共增益与声线，设计有区分力的完整第三句对照，分别问虚实、暗/压低感和前后连续性。旧F本次未达目标，不直接把数值指标当剂量计算器，也不沿原单通道自动加码。音高路线/字长和主唱发声分开验证，再考虑必要组合；作者曲线与控制数值仅作研究证据，不作为生产数组。

本轮未实施新候选或更新Skill。Skill已有分轴、跨句校准和局部接受边界，缺的是把这些要求落实到当前交付；继续重复加文字不能代替新声音验证。前一次把版本未同步解释为主要问题不充分：它确实存在并已修好，但技术等价没有解决剩余音乐/发声目标。精确病因仍未隔离，作者旧模型/原声缺失也不能由当前书面图补造。
