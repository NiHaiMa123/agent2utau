# 发音姿态：六条件气声单因素响应检验

用户授权“下一步”后，执行此前冻结的6条件、同剂量、同函数族BREC对照。目的是检验同元音气声方向线索并检查反例，不逐个字扫参数或直接修整曲。当前结论是**控制路径和可测响应已验证，口型改善、泛化规律与副作用听感仍待评价**。Skill和发布工程没有改动，已通过抱C保持。

## 实际执行

每条件A/A-repeat/B，完整新variance11/acoustic101/vocoder，共18套新波形。B仅增加有限BREC -10 UI；保留原BREC基底，抱原A/C已有-3控制保留，峰值总控制为-13。自己设计的Q5建立/退出按原生5tick网格转写，名义元音内留10ms、80ms建立、末80ms开始70ms退出；没有复制通过样本的预测或曲线。

两阶段实际Normal75/Classic25、depth0.6/steps20及模型/运行依赖固定。六组实际variance条件与新预测精确相等，实际fresh acoustic输入只breathiness变化；F0、vocoder目标、phones、语言、speaker、张力/有声人工控制和原SHFC保持。各字完整原生时钟及float32 divide20/multiply12/divide100控制采样精确，最终`clip(pred+delta)`精确，特征裁剪0。

六组A均与原已绑定自身波形精确，含原v02五条件和此前已通过抱C；六组重复差0。原生ApplyDynamics处理全部18套波形，当前这些句DYN均为unity，乘法与输出精确；固定人声1.5/伴奏.7，没有归一化、压缩或响度匹配。邻句原自身波形按原顺序明确复用，五个原版A片段与当前交付人声/混音PCM精确。C保护组以已接受C为基线，未取消其SHFC。

## 实施纠正与保留

通用受控检验器原先只有manual_cancel；新增显式manual_delta模式，保留默认取消检查，仍要求单通道、完整不变条件、原生算术精确及支撑范围。还拒绝被特征裁剪掩盖的支撑外人工变化。新3项反例/隔离测试与原测试共88项通过。

一次原生导出加载声码器时发生0xC0000005初始化访问冲突，失败日志保留；相同输入普通重试成功，未改模型、配置或种子。首次1tick密集节点编码与native先转5tick曲线的采样不等，独立检查以0.072特征最大差阻止了任何新seeded合成；所有旧草稿/原生缓存波形保留，改为原有5tick节点上的有限Q5，剂量/名义支撑未变、最终原生采样精确，不放宽门槛。

一次在编译完成前重复启动的导出只读到旧cohort并跳过已有旧导出，日志保留，不算新版本完成；随后新5tick目录逐组正确导出并校验。所有实际18套seeded新波形均来自最终5tick版本。
