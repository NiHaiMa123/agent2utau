# 虚实一致性只读评估

入口：`python -m agent2utau.evaluation.phonation --manifest <manifest.json> --out <新目录>`。

它测量当前纯人声PCM的可比声学差异，输出逐元音/入口/主体/退出的观测、参考覆盖与跨版本响应；不读取制作expectations，也不自动调VOIC/BREC或判定歌曲通过。当前算法是透明的周期性/频谱代理，尚无已验证的听觉虚实刻度。

## 三层判断

| 层 | 判断对象 | 输出与使用方式 |
|---|---|---|
| 实际执行 | 当前speaker、预测和人工增量 | 沿用原生probe/输入核验，定位改变了哪个控制；不作为虚实真值 |
| 声学观测 | 可靠元音窗口中的周期性、噪声状频谱、谱倾斜和RMS | 本入口输出；分别报告，避免把更响/更亮当更实 |
| 听觉校准 | 用户在连续上下文中的虚实、距离感及一致性 | 精确记录版本/时钟/范围；当前仅有限相对标签，不能从代理倒填通过 |

相同配比或更接近模型特征目标不保证同一演唱状态；代理变化也不直接证明改善。相邻句可以声学特征不同而听觉一致。

## 测量定义及质量掩码

固定算法/配置后再测实际作品，配置与版本均写入结果。不为某次反馈事后调权使得分顺眼。

- 当前默认10ms hop，窗口至少8个实测周期、20–80ms，必须完整处于一个原生元音中。辅音/呼吸不参加；短元音、低电平/削波风险和不足周期保持unknown。
- 两个独立实测F0轨必须绑定同一PCM SHA及绝对时钟。中心以及窗内两轨原采样时间的并集/边界上相差超过50c，或窗口内无声、不稳定、F0跨度超过20c时，该窗不参加。20c为v2更保守的默认质量配置，不是听感阈值；v1的80c曾放过明显受运动影响的窗。显式旧配置不会被工具悄悄改写。
- `period_lag_ncc`：在实测周期附近±3%内的13个分数延迟取最大归一化相关；`periodicity_ratio_db_proxy`为`10log10(r/(1-r))`，极端值标censored。它是稳态周期+噪声假设下的代理，不是经验证的周期能量分解或Praat HNR。
- `highband_flatness_db`：Hann谱2–8kHz功率的几何/算术平均比，频带受Nyquist限制。高频带总功率相对整谱低于−80dB时标unknown，避免将数值底噪的平坦当成真实噪声。越接近0越平坦，但共振、音高、EQ和声色也会影响它，不直接叫漏气百分比。
- `output_spectral_tilt_db_oct`：120–5000Hz输出对数功率谱对log2频率的回归斜率；未做共振校正，不能推声源闭合。RMS单独保留，二者不进入虚实代理合成。
- 入口为元音时间比例前25%，主体25–75%，退出后25%；这是本算法的观测阶段划分，不冒称音乐到达真值。主体至少5个有效窗才有主描述；每阶段原帧、拒绝原因和覆盖均保存。

窗内归一化仅用于数值尺度稳定，不改试听PCM。纯人声/独唱角色是调用者声明，算法没有自动证明声源分离、无混响或单声部；当前仅支持有限单声道人声，混音/多声部拒绝。

## 条件参考与相对代理

参考句由调用者根据有范围的听觉记录声明。当前实现只匹配**相同完整phone符号、实测主体中位音高相差不超过3半音**的其它元音；剔除同一unit自我参照。3半音只是粗条件范围，仍有音区/共振/音乐阶段混杂；无匹配不借其它元音补齐。

对每项主体观测，用参考元音的中位数和MAD取得尺度，尺度下限3dB。每个元音一票；不让长字帧数主导参考。v2分别报告周期性比代理和高频平坦度的原始差及标准化差`axis_contrasts`；一条参考标`singleton_reference`。

`consistency_distance_proxy = sqrt(z_periodicity² + z_flatness²)`仍只作声学差距描述。v1的`(z_periodicity - z_flatness) / sqrt(2)`合并代理撤下；`relative_firmness_proxy`及句级signed字段保留为null，`firmness_assessment=null`。输出schema升级为2，输入manifest仍为1，旧封存结果不改。

不同数字滤波可在相同已知组分信噪比下改变平坦度；动态音高也可降低周期性。因而不将两个分量的投票当成听觉“实感”，也没有通过阈值。一条参考仅提供很有限的条件对照；高度相关的两个分量不构成独立证据。参考内部也可能因音色/共振有较大声学差距而被用户认为一致，不能依代理反驳用户。

每句报告可比元音数及比例。当前工程质量配置要求至少75%可比才给全句覆盖状态，否则`insufficient_matched_coverage`；即使达到覆盖条件，仍只标`partial_descriptive_only`、`perceptual_consistency=unvalidated`。已有少量匹配的距离只代表该子集，不替代整句结论。

跨版本同一元音的变化另列`paired_changes`。它支持定位某控制是否改变了输出声学特征，与是否更接近邻句/是否好听分开。

## 显式输入

manifest v1只接受以下字段；文件引用均为`{"path":"...","sha256":"..."}`：

```json
{
  "schema_version": 1,
  "signal_role": "pure_solo_vocal",
  "project": {"path": "current.ustx", "sha256": "..."},
  "regions": {"path": "regions.json", "sha256": "..."},
  "versions": [{
    "id": "current",
    "audio": {"path": "vocal.wav", "sha256": "..."},
    "absolute_offset_s": 0,
    "f0": [
      {"file": {"path": "FCPE.npz", "sha256": "..."}, "audio_sha256": "...", "absolute_offset_s": 0, "detector": "FCPE"},
      {"file": {"path": "RMVPE.npz", "sha256": "..."}, "audio_sha256": "...", "absolute_offset_s": 0, "detector": "RMVPE"}
    ]
  }],
  "reference_version": "current",
  "reference_phrases": ["s01", "s02"],
  "phrase_order": ["s01", "s02", "s03"],
  "config": {},
  "knowledge_context": {"path": "knowledge_context.json", "sha256": "...", "decisions": []}
}
```

`regions.json`为按绝对时间排序且不重叠的列表，每项仅含`id`、`phrase_id`、`phone`及`support_s:[start,end]`。来自当前实际phones和所有权，另绑定其原生出处/回写等价检查；project仅作身份SHA，本入口不自行验证region与工程的语义等价。没有实际phone依据不伪称已验证元音时钟。

F0 NPZ包含等长一维`times`（相对该音频秒）、`f0_hz`、`voiced`；F0引用与音频须用相同绝对offset且覆盖整份音频。音频错误、哈希变动、时间域不匹配、重复检测器、重叠区域、未列入的phrase及未知字段均拒绝。两个不同检测器名称仍是调用者声明，不自动证明模型独立性。

知识上下文沿用根目录知识接入门禁，显式保留正反例和未验证范围。配置JSON可省略具体配置项以使用当前默认，但结果会完整写出实际配置。输出目录必须新建。

## 输出与生产使用

同字跨版的开发考核使用`evaluation.phonation_audit.compare_pair(left_words, right_words)`：要求相同元音身份/支撑/乐句，在双方均可靠且音高相近的主体中心取交集，至少5个共同点；先取每元音配对差中位数，再等元音权重汇总。它不消费听觉标签、参数值或计划期待，不输出虚实分。见[已有标签考核](../reports/production/phonation-existing-label-audit-20261017.md)。四组方向吻合仍共享C且声色混杂；D/E整体近似不等于测量完全相等，G/H/I没有独立虚实标签也不能用来计算声色误判率。该考核不建立可辨阈值或跨句评分。

- `result.json`：所有输入绑定、质量/阶段窗、原指标、参考IDs/尺度、相对代理、覆盖及跨版本变化。
- `words.csv`：逐元音可查看的主体指标和参考差距。
- `report.md`：逐句覆盖与局限。工程/音频原文件保持，只写指定新目录。

将当前候选和相邻句放在同一秒轴上评估。先区分可比区域偏离、不可比缺口、声色/响度混杂及已确认的听觉问题，再决定有限对照；不能从一个代理直接反算VOIC/BREC。当前样例只属开发观察，没有独立新曲/盲听留出校准；未来可在逐首制作反馈中补同元音/音区的听觉参考，不因本工具存在重开大批生成。

## 测试样本与试听标签

2026-10-17按用户授权建立独立测试库，见[测试报告](../reports/production/phonation-benchmark-20261017.md)。有限矩阵含324条数学信号与84条本机声库孤立元音。前者有组分信噪比真值，用于检查方向/增益/滤波与音高运动混杂；后者7元音×3音区×2组VOIC×2组BREC，仅核验实际控制执行，不从旋钮造听感标签。当前歌曲前三句A/B仍是已暴露的开发语境，不能充作盲测留出。

同一元音/音区及其全部控制派生样本留在同一分区。数学信号108开发/216程序留出，声库样本56开发/28条件留出；都是同生成器/同声库的有限验证，不是独立新歌泛化。先冻结算法再测留出，不为留出结果改权重后继续称其留出。新增条件不得自动补作原歌曲同元音参考，尤其不能以孤立元音替代实际连唱语境。

试听包绑定catalog、样本PCM和A/B次序SHA；25组初始开发对照包含21组因素对照及4组重复/音量反例。分别记录实感、气声、贴耳、音量、自然度、声色；允许没区别/不确定，null为待评，未知不倒填通过。保留原始导出增益；音量派生反例另有明确增益记录。

标签核验入口：`python -m agent2utau.evaluation.phonation_calibration --catalog <catalog.json> --packet <packet.json> --ratings <ratings.json> --out <新文件.json>`；加`--require-complete`要求全部轴/试听者齐全。它拒绝变动PCM、换A/B次序、跨分区泄漏、缺轴/重复记录及把旋钮值当答案，仅核验标签出处；不会拟合虚实阈值或自动调歌。测试页下载JSON后通过此入口回填，再决定是否有足够证据设计校准规则。

当前用户反馈孤立样本“基本听不出”，故原25/21组问卷暂停作为下一步听觉任务，旧pending不倒填成逐项无差异。校准顺序改为完整音乐句的少量宽端点→确认可辨/虚实方向→区间细分→真实连唱一致性检查，见[句子粗区分记录](../reports/production/phonation-sentence-coarse-20261017.md)。孤立样本仍作工程测试，不用增加近似样本数量替代区分能力。组合端点不证明独立通道效应；固定整句RMS匹配只隔离一项音量混杂，不能宣称等感知响度。用户明确要求较大差异仅授权研究端点，不是歌曲自动加码。

完整句试验已取得有限的相对虚实/额外发声描述，换句试听还会得到整体偏好，如“两个版本差不多，都好于另一个”。这些偏好和整体近似单独入结构化来源，不折算成虚实/自然度或“压低声音唱”方向；六轴问卷不支持的内容另存，不因字段null丢弃已收到反馈。生成前冻结的专门轴预期若缺相应标签，保持unknown，不用偏好或声学代理宣布命中。参考[换句偏好与预测复核](../reports/production/phonation-second-context-preference-review-20261017.md)。同一三版用户事件导出的多条关系不算多个独立样本，旧报告/模板/预期不刷新。

## 来源与方法边界

F接入前三句诊断随后获用户“后面的更好，基本一致”，见[连续正例](../reports/production/phonation-context-F-confirmed-20261017.md)。这是明确的第三句相对前两句虚实基本一致标签，覆盖该连续PCM及一次固定增益的组合，不是逐元音等值、单因素成效或工程已采用。可用于后续正例复核；新PCM尚无独立F0观测，旧测量覆盖和未校准状态保留。

后续D/F专门反馈已补充F更实、D更暗、整体偏好F；旧pending保留，追加记录见[非C反馈核对](../reports/production/phonation-nonC-df-feedback-20261017.md)。两项虚实代理汇总方向与新标签相符，输出谱倾斜的直接明暗排序却不符；保留两种能力状态，不按单例改权重或翻符号。当前新增一个非C的交叉关系，仍不是跨句刻度或听觉准确率验证。

已有完整句的相对标签可作为虚实锚点（A比C虚、B比C虚、D比C虚、C比F实），但C同时有“压低声音唱”的听感，不能作为理想实声目标。新句G获“暗、压低声音、不够清亮”的澄清，按声色描述另存；H/I整体优于G不等于新虚实排序。下一次评价先读取这些SHA绑定反馈和试听索引，不再要求用户重定义已记录的实与虚；跨句锚点仅帮助理解概念，不能代替新句听觉排序或校准数值阈值。

Praat说明周期性及元音/频谱因素对HNR的影响，支持必须记录条件，未给本实现或本声库背书：[Harmonicity](https://uvafon.hum.uva.nl/praat/manual/Harmonicity.html)。较长周期窗对动态变化更敏感，质量掩码需保留：[Harmonicity AC](https://fon.hum.uva.nl/praat/manual/Sound__To_Harmonicity__ac____.html)。声质分析保留噪声，避免将滤波F0追踪等同声质测量：[Praat方法选择](https://www.fon.hum.uva.nl/praat/manual/how_to_choose_a_pitch_analysis_method.html)。

本工具没有调用Praat/Parselmouth，也没有实现其CPP或声门反滤波，不报告这些名称的测量值。表1 MEAS:D10/D11/D12及PER:S1的旧measurement_validated状态保持；合成信号测试只验证本实现有限性质，不升级旧协议或听觉泛化。
